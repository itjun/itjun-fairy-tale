## 美术路线（已确认：矢量化现有精灵）

最初选定的「重绘」路线无法执行：图像生成工具不能传入参考图，单张输出约 1152×864，不足以生成每格 1024 的精灵，且无参考重绘会偏离女儿原画（已生成的三张概念稿中火箭、兔子首领的造型和颜色都已改变，仅作存档，见下方链接）。

用户选定「矢量化现有精灵」：保留原画造型与颜色，描边在任意分辨率下保持锐利，彩笔质感作为纹理保留。

实现方法（`scripts/build-gun-nac-art.mjs`）：

1. 每格 256 源图取一个 22 色的确定性 k-means 调色板，保留原画颜色。
2. 颜色距离小于 40 的聚类合并；亮度低于 80 的深色聚类全部合并为一种墨色，描边因此成为实心的线，不再碎成深浅斑点。
3. 对标签做 3×3 众数滤波，去掉散点。
4. 每种颜色的遮罩用三次插值放大到 1024，再模糊（半径 4），逐像素取最强颜色。边界因此变成平滑的彩笔轮廓。
5. 透明度由放大后的遮罩推出，抗锯齿边缘保留。

背景（hangar、field-0 至 8）不做分割，使用 Lanczos3 放大到 2560×1920 并轻度锐化。

已知限制：

- 精灵填充仍保留源图的彩笔颗粒，所以大面积填充会有轻微的颗粒斑块。这是有意保留的彩笔质感，不是噪点。
- 白色与浅色区域偶有浅蓝斑点，来自源图的颗粒，在 1080p 下不明显。
- 调色板与合并阈值是按现有 24 个精灵的 1024 效果定下的，若新增美术需复核。

预览（1024 格，缩小展示）：

- 飞机与道具：`craft` 图集，火箭、飞机、飞碟、兔子、雪人等，描边统一。
- 首领：`bosses` 图集，月亮、坦克、美人鱼、橡子、猫、熊猫等，轮廓干净。

## 验收

- 性能守护：`tests/performance/gun-nac-render.perf.mjs` 在真实 Chrome 硬件 GPU 上，1080p 窗口 2 倍像素比（战场 2879×2159），持续射击 6 秒：中位帧时间 16.7 毫秒，95% 分位 16.8 毫秒，阈值为 20 与 40 毫秒。
  - 本次复测时，系统内存压力较大，曾出现 33 毫秒的瞬时结果（约两个垂直同步周期）。随后用「源图重采样」与「矢量化」两版图集做了对照，两版都是 16.7 毫秒，因此该波动来自系统负载，不是新美术造成。
- 单元与回归：`npm test` 所含的 339 项非性能测试全部通过；新增高清图集尺寸检查与画质默认值、切换、存储失败的检查。
- 固定输入回放：`tests/gun-nac.test.mjs` 中的逐帧一致与九区飞行仍然通过，逻辑未改。
