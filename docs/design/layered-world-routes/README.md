# 九个世界的跳台路线

2026-11-24 设计稿。孩子走到第一处断岸时，站在安全的台上就能看见下一块落脚点。往高处跳、向下探洞、回头搭机关，都会把人带到原本走不到的地方。

| 设计稿 | 这一段怎么玩 |
| --- | --- |
| [沙丘分岔](dunes.webp) | 从低岸跳上分岔口。上路爬岩找日镜，下路穿洞探泉。两路在绿洲的棕榈台汇合，再越过最后的低谷。 |
| [钟楼折返](tower.webp) | 从低街往右进塔，搭指针回到左边的屋顶，再向右沿高窗登上钟楼。下层软网接住失手的玩家，敲钟后高处的吊桥才放下。 |
| [潮洞穿层](tide.webp) | 从崖上往下进海蚀洞取灯芯。回程可以沿石阶上岸，也可以搭涨潮木筏升到半高码头，再从错层礁台跳上灯塔。 |

## 同一个世界也要换走法

| 世界 | 必须经过的高低路线 | 岔路与汇合点 |
| --- | --- | --- |
| 彩虹花园 | 沿河岸下到分水槽，再踩长起来的花叶登上渠顶。 | 花茎高路经过花粉山脊，荷叶低路穿过桥洞，两路在水磨轮换乘。 |
| 家人小镇 | 由街巷进钟塔，搭摆针跨过楼层，再从高窗折回钟亭。 | 外侧屋脊能提前碰到守卫，内侧阳台更宽；两路都能敲钟放桥。 |
| 甜甜城堡 | 从收货台下到食材地窖，踩饼干阶梯折返烤坊，再走上送餐口。 | 上层输送带穿过烤炉，下层餐架宽但绕远，在出餐窗交单。 |
| 贝壳海边 | 从潮崖下到礁洞取灯芯，再搭涨潮木筏换层点灯。 | 干石阶随时能走，木筏缩短回程，两路在码头汇合。 |
| 风车草地 | 先下到背风谷控制风筒，乘上升气流越过断崖，落在投递台。 | 一股风送上山脊，另一处低台可以换乘第二股风，最后抵达同一座风车。 |
| 雪人乐园 | 从雪脊放球，滑下冰谷扳岔轨，再沿破开的冰梯爬上山口。 | 熟练的玩家能从高处抢到岔轨，晚到可以走雪球撞开的下层通道。 |
| 蘑菇森林 | 巢边能看见高处的鸟和低处的树洞。树冠在不同枝杈间折返升高，树根洞先降到溪底再绕回上层石龛。 | 继续沿用两条寻鸟路线和原有捷径；长枝中途以断枝换层，树根洞以溪桥换岸。 |
| 卡通梦工场 | 从站台登上列车，在高架站下车，再进低处检修轨道，最后回到高处车顶。 | 高架岔轨越过积木镇，检修线从桥下穿过，在礼物站换乘。 |
| 沙漠绿洲 | 「暗河水纹」从断沙丘起步，先下洞拓水纹，再沿岩壁折返登上日镜台。 | 地表岩脊适合打怪和收集，洞里有泉眼和两处神灯；回到绿洲后还有一段升降。 |

## 试玩时怎么看

- 逐房试玩开场、普通探索、战斗和首领场。开场的第一屏就能看到两处不同高度的可达落点；较长的地形段中途也有换层动作。
- 用四位家人的基础移动和跳跃走通主路。在上下两条支路上分别走到汇合点；再尝试一直往右走，检查哪里还能贴地绕掉整段机关。地形允许短平地，供孩子观察、打怪和调整起跳位置。
- 战斗房在不同高度安排守卫，栅栏前有路通到每一只必须击败的小怪。首领战用错开的宽台换层躲招，出生、复活、洞口和机关操作处留出站位。
- 以实机镜头检查脚下、头顶和下一落点的净空。用正常角色速度试跳；地形图上的箭头只表示走向。每个世界保留孩子已经熟悉的机关、操作键与彩笔素材。
