本次选定三个方向，先在第七个世界「蘑菇森林」接入[树冠救援](canopy.jpg)。[潮汐灯塔](tide.jpg)保留退潮进洞取灯芯、涨潮乘筏登塔的玩法。[玩具列车](train.jpg)保留列车停车等候、孩子选轨和开路送货的玩法。

## 树冠救援

从猫头鹰妈妈的鸟巢出发，可以先上树冠，也可以先钻进树根。两只幼鸟都会跟随角色，回到妈妈身边才算送达。送回第一只后可选本领；两只都回巢后，古树守卫在鸟巢前登场，低处的藤梯和枝台可用来躲招。打赢后往右到终点，进入下一世界。

| 路线 | 游玩段落 | 回巢 |
| --- | --- | --- |
| 树冠 | 穿蘑菇坡敲铃、乘风叶到高处打开枝桥、过桥解藤结、沿紫藤树梢找到幼鸟 | 外伸的树干可攀爬，沿解开的藤梯下到鸟巢 |
| 树根 | 在高低石龛接齐三只萤火虫点灯、经过回声石窟推出树皮桥、踏过地下溪桥找到暗门、到暖灯育巢接幼鸟 | 从幼鸟身边的树皮门回到妈妈身边 |

普通种子提供两条回巢路线。有树心通道的种子，在第一只树冠幼鸟跟随后，还可以从树梢直接前往地下萤火灯。出入洞口继续使用向上操作；幼鸟会跟随穿洞、攀爬和复活。走到机关中央就能启动，沿用四位角色的操作。

第七世界的新局使用独立关卡编号，原有森林续关和成绩继续按原地图解释。新局记录两路机关、随行和回巢状态。真实时长由选路、战斗、探索与孩子自己的节奏决定。
