# 《小雪人姐妹》（FC《雪人兄弟》彩笔重制版）设计说明书

本模块是《花园王国》首页右上「怀旧游戏」中的第二款完整游戏，致敬 1991 年 FC 版《雪人兄弟》（*Snow Bros.*），按项目既定的**女儿彩笔画风 + 4∶3 中央舞台 + 左右侧栏 HUD + 本地 Web Audio 芯片原声**架构打造，完整收录 **50 层单屏动作关卡、5 大 Boss、过关老虎机、隐藏宝物跳关、Time 竞速模式与 1P / 2P 同屏合作**。

[官方参考资料档案](reference-catalog.md) · [彩笔图集分镜](storyboard.webp)

---

## 1. 彩笔世界观与角色定位

- **主角姐妹**（2026-11-26 起直接使用冒险游戏里女儿原画的两姐妹素材，见 `public/assets/sister-*.png` 与 `little-*.png`，由 `scripts/build-snow-sisters-art.mjs` 裁切进角色图集）：
  - **1P 姐姐**：红裙、黑色粗笔线条与原发型，站立与攻击姿势均沿用冒险游戏原画；标签为金色 `1P 姐姐`。
  - **2P 妹妹**：紫裙、同样的粗彩笔线条与身高差；标签为薰衣草色 `2P 妹妹`。
  - 连锁雪球跟随推球者：1P 姐姐是金黄雪球加星星（引擎里 `color: 'p1'`），2P 妹妹是薰衣草紫雪球加爱心（`'p2'`），与红裙、紫裙拉开（2026-11-27 选定方案 A）。旧存档里的 `blue` / `red` 读档时自动转成 `p1` / `p2`。
- **剧情背景**：热呼呼王国的「阿奇奇大魔王」用暖风占领了冬日城堡，把姐妹俩变成了圆滚滚的雪人宝宝，还把两位花园小精灵公主锁在 50 层塔顶！姐妹俩联手向高塔冲刺，每 10 层击败一位大守卫，最终在双泡泡石像前打破诅咒迎来日出。
- **视觉规范**：
  - 逻辑战场严格锁定经典 **`256 × 240`（4∶3）**，由 Three.js 正交相机绘制 `public/snow-sisters/` 彩笔透明图集与五大主题彩纸背景；
  - 宽屏左右留白转化为彩笔信息侧栏：左栏承载 1P 分数、残机、`S-N-O-W` 收集槽与药水状态；右栏承载最高分、当前楼层 / Time 倒计时、2P 状态（未加入时显示随时参战按键提示）、暂停与键位提示。
  - 侧栏宽度为 `--sn-rail: clamp(9.4rem, 7vw, 13rem)`，字号随窗口 `clamp(13px, 1.25vw, 18px)` 缩放，战场宽度为 `100vw - 2 × 侧栏 - 1rem` 与 4∶3 高度取小。最高分拆成「最高分」小字加数字两行，避免被侧栏裁切。
  - 2026-11-26 已确认的第一轮打磨（对照 `snow-sisters-polish-mock.jpg` 的 A 方案）：雪地与五大主题背景为彩笔原画；平台改为彩笔砖块加白色雪顶（`buildBrickBankSvg`），4∶1 纹理按宽度平铺，显示高 11 单位、碰撞仍以原落脚线为准；球形敌人加雪帽并整体放大到 1.14 倍（`buildEnemiesSvg`，只改图集不改碰撞盒）。道具、墙体与 BOSS 仍是旧版素材，未在本轮范围内。

## 3. 五大主题塔层结构（共 50 层）

1. **第 1～10 层 · 城墙冰阶（Ramparts）**：蓝灰彩笔石砖城堡，教学推雪球、连锁雪球与斜坡滚击；第 10 层守卫为 **巨蜥莫格拉**。
2. **第 11～20 层 · 机械糖屋（Candy Clockwork）**：薄荷青与奶黄糖果砖结构，第 12 层起引入蓝忍者（飞镖+旋风穿墙），12 层藏有首枚跳关红包；第 20 层守卫为 **炮弹蛙卡玛吉**（上下瞬移发射爆弹兵）。
3. **第 21～30 层 · 云端斜坡（Cloud Slopes）**：紫魔怪学会平地直滚、喷火怪解锁向下喷火、黄猴守卫高台；24/26/28 层顶部出现相扑手（20,000 分红包）；第 30 层守卫为 **双怪鸟**（产卵孵化 + 三段变色俯冲）。
4. **第 31～40 层 · 熔岩地牢（Magma Vaults）**：深红岩浆暖色调，火焰怪抛掷燃烧弹融化雪球，多层窄井与踩雪球上高台机关；第 40 层守卫为 **大鼻绿魔**（火球可被裹成雪球反击）。
5. **第 41～50 层 · 暗夜尖塔（Night Spire）**：深靛星空背景（配 *Dosskoi Snow* 紧张旋律），加入底部循环深坑、高速独角冲撞怪与蓝蝙蝠；第 50 层最终决战 **双泡泡石像**（5 类泡泡 + 缓降尖刺天花板），击败后进入日出结局。

## 4. 独有模式与本地保存

- **隐藏 Time 模式**：在标题界面选中模式切换或依次输入 FC 秘籍（`上×2、右×8、下×2、左×8`）解锁「限时 2 分钟挑战」，以最速通关与极限高分为目标。
- **独立存档**：游戏状态保存至 `garden-snow-sisters-v1`，最高分保存至 `garden-snow-sisters-record-v1`，监听桌面 `garden:prepare-close` 自动落盘，零外部网络请求。

## 6. 第二轮美术重画（2026-11-27 已确认并开发）

三张设计稿（概念示意，具体造型以开发为准）：

- [道具重画](snow-sisters-items-redraw-mock.jpg)：药水、寿司、红包、雪球、火焰、泡泡、冰锥、公主。
- [五大 BOSS 重画](snow-sisters-bosses-redraw-mock.jpg)：巨蜥、炮弹蛙、双怪鸟、大鼻怪、双泡泡石像。
- [雪球配色与制作人员表](snow-sisters-snowball-credits-mock.jpg)。

要点：

1. **道具**：外轮廓加粗到 4～5 个逻辑像素，去掉高光细线和小字，色块填满并带蜡笔斜排线；药水瓶身加大、字母放大加粗（保持 S / P / R / G，设计稿里的 R B Y G 是示意错误）；寿司按三档放大；红包改红金两色大字。32 像素大小下一眼能认出种类。
2. **BOSS**：按稿子换成大体型造型，保持原版分工（巨蜥、炮弹蛙、双怪鸟、大鼻怪、双石像）；屏幕上画 48～64 像素；每个 BOSS 补「待机／预告／受击」三个姿势，预告姿势与现有出招时机对齐。碰撞盒和数值不改。
3. **雪球配色**：问题是 1P 红裙与珊瑚红雪球相近。三个候选见下文，待选。
4. **制作人员表**：不透明奶油纸板、深棕大字、紫色虚线边，与稿子一致；开发时用截图确认可读。
5. **不改**：玩法、存档、手柄、碰撞、分数。

## 7. 高清渲染翻新（2026-11-27 已确认并开发）

**原则**：怀旧的是玩法与设计思路，画面不要像素风和模糊感；不以省内存为目标，只要求游玩流畅（目标 60fps，4K 全屏也要稳）。逻辑战场仍是 256×240 的 4∶3，碰撞、手感、数值不变。

现状（实测）：角色、敌人、道具图集每格 256 像素，BOSS 每格 256，雪地背景只有 768×576，平台图 1152×288，墙体 128×128；渲染器像素比最高 2。大屏上会发糊。

| 项目 | 现状 | 方案 |
| --- | --- | --- |
| 角色、敌人、道具、BOSS 图集 | 每格 256 | 每格 1024（四倍），生成脚本直接以矢量放大输出；冒险游戏里的姐妹原画用原图最大尺寸 |
| 背景、标题、结局图 | 768×576 / 1024×768 | 2560×1920，保留蜡笔纸纹 |
| 平台、墙体 | 1152×288 / 128 | 平台 4096×1024，墙体 512，砖缝与雪顶按大块彩笔重画 |
| 渲染器 | 像素比最高 2 | 像素比跟随屏幕（最高 3）；多重采样抗锯齿；纹理开各向异性过滤与 mipmap，不用最近邻 |
| 动态效果 | 简单 | 雪球滚动带阴影，踩雪溅起粒子，击杀时彩笔星星与雪花爆开，BOSS 出招预告加发光圈，背景雪景做三层视差慢动；减少动态效果时只保留提示 |
| 文字与 HUD | 随窗口缩放 | 保持，侧栏图标也出高清版 |
| 性能守护 | 无 | 加一条性能测试：整局画面帧时间中位数、最差帧；如果某台机器掉帧，只在设置里提供「画质」降一档，默认最高 |

**取舍**：安装包会大一些（图集预计由 1.4MB 增到 20～40MB），首次载入多半秒到一秒，但进入游戏后运行时显存占用可控，不影响帧率。

**范围**：与第 6 节重画一起做；开发顺序：先出新图集和背景，再改渲染器和特效，再跑测试、构建并安装桌面版，最后在 1080p 与 4K 窗口各截图验收。


### 7.1 落地结果

- 图集：角色、敌人、道具每格 1024（5120×4096），BOSS 4096×4096，背景与标题、结局 2560×1920，平台 4608×1152，墙体 512。SVG 按 4 倍分辨率重新栅格化，原画姐妹用 928 像素原图；生成脚本 `scripts/build-snow-sisters-art.mjs` 按格并行渲染，整套约 45 秒；调试单张用 `SNOW_ART_ONLY=items,bosses`。道具与 BOSS 的重画造型在 `scripts/snow-sisters-art-redraw.mjs`，文字（S／P／R／G、祝、寿、分数）用本机安装的 LXGW WenKai。
- 渲染器：像素比最高 3，抗锯齿，纹理各向异性与 mipmap，透明图集预乘 alpha 并收进格边 0.3%，特效画布贴图按 4 倍绘制。
- 特效：脚下软阴影、道具光晕、雪球滚动尘雪、起跳与落地雪团、击倒时雪花与金星爆开、BOSS 受击火花与击破闪光、雪片弹丸光尾、BOSS 出招预告（脚下红光、蓄力抖动、头顶感叹号，对应各 BOSS 出招周期）、背景视差与两层飘雪。减少动态效果时只保留阴影、光晕和预告提示。
- 画质：默认「最高」；暂停页与塔楼设置里有「画质」按钮可降到「标准」（像素比最高 1.5、粒子减半、雪花减少），只手动切换，从不自动降。
- 制作人员表：奶油纸板、深棕大字、紫色虚线边，来回缓慢滚动并停留，便于阅读。
- 测试：`tests/snow-sisters.test.mjs` 增加图集尺寸与雪球配色检查；`tests/performance/snow-sisters-render.perf.mjs` 在真实 Chrome 硬件 GPU 上打第 30 层 BOSS，量 2880×2160 画布的帧时间（实测 60fps，中位 16.7ms），没有 Chrome 或没有硬件 GPU 时自动跳过。另手动在 1080p、4K、1080p 3 倍像素比窗口测得 60fps。
- 未覆盖：Windows 与实体 Xbox 手柄未实测；敌人（小怪）图集只随 4 倍分辨率重新栅格化，造型未重画。
