# 武器发射与小怪进攻

2026-11-16，按用户截图与反馈直接调整现有游戏。沿用彩笔人物、武器素材、地图结构、三条命和手柄操作。

## 本轮规则

- 八种武器的主弹道命中第一只敌人后消失，护盾和硬壳也会消耗本发。泡泡和花种在命中处爆开；连锁、分裂、传奇接力属于已取得的奖励效果。
- 同种武器同一时间只飞一轮。双发、叠加和扇形增加这一轮的数量，等所有弹道及奖励追加效果结束后才能再发；各武器原有最低发射间隔继续生效，贴脸也不能每帧发射。
- 攻速本领同时提高弹道速度和缩短最低间隔，仍等待本轮结束。弹道穿过平台，未命中时飞到发射时屏幕边界；弯刀追逐过久会直飞出屏，避免一直绕圈占住发射。
- 火龙改为飞行火焰，花种改为穿平台飞行、命中开花，星镖命中消失；星镖的回程分裂奖励改为命中后向后散星。名称、素材与伤害差异保留。
- 巡逻、跳跃、飞行、冲锋、护甲、硬壳和辅助怪都能主动攻击。已有近地攻击、扇形、投掷与召唤保留；缺少弹道的怪增加瞄准玩家的攻击。射手可瞄准高台。
- 小怪休息阶段系数从 0.75 降至 0.5，独立预告仍至少 0.7 秒，轻松至少 0.9 秒；远程出手错开至少 0.5 秒，同屏主动怪最多三只。每间有敌人的普通房分段补 1～3 只守卫，优先不同动作、空闲落脚点和原有安全间距。
- 首领继续使用已有每 1.5 秒最多承受最大血量 12% 伤害的规则，不额外加厚基础血量。

## 存档

保持第 11 版。追加守卫在原生成流程结束后分配尾部编号，不改变平台、原敌人、宝物和门编号。读取本轮之前的第 11 版存档时，只补齐尾部守卫；已清房间与已通过波次不重新打，也不凭空增加击败积分。历史成绩、花园、画册和独立小游戏保留。

弹道保存发射武器、玩家与屏幕边界。恢复后依据仍在飞的弹道决定能否再发；旧弹道按武器种类归属。暂停不推进弹道、回气和怪物行动。

## 验证范围

- 回归测试覆盖八种武器双向空放、首次命中和护盾、双发占用、攻速、分裂与花田、保存恢复、实际引擎手柄长按与暂停、每种小怪重复主动攻击、第 11 版旧局补齐。
- 既有首领测试覆盖八个世界基础弯刀和叠满武器。自动操作结果不等同于孩子试玩，实体 Xbox 手柄与 Windows 仍需实测。

### 本轮结果

- `python3 build.py` 内的 199 项功能测试与 1 项性能测试通过。八个世界基础弯刀约 14～14.68 秒击败首领，八种叠加武器约 12.47～12.61 秒、至少三轮首领出招。
- 八个世界各 40 个种子验证守卫增量：开场、战斗、精英每间加 3 只，机关房每间加 2～3 只；地图可达性、间距和怪物站位检查通过。
- 浏览器使用独立成绩库试玩，确认弯刀击败小怪、小怪主动扣血、暂停正常；实际引擎模拟手柄长按与读档测试通过。
- 首次桌面手柄脚本在换难度、开始探险和菜单导航处失败。后续排查确认测试窗口失焦，并找到普通菜单额外确认和结算焦点丢失；测试短按也改为等待实际采样。修复与扩展验证记录在 `../room-roguelite/controller-checklist.md`，实体手柄与 Windows 仍需单独实测。
