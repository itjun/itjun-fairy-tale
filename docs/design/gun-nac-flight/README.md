# 加纳战机

从《花园王国》首页的「加纳战机」进入机库。「开始游戏」默认从月面基地出发。途中可以暂停，保存并回花园，下次在机库点「继续飞行」。

| 区域 | 路上的打法 | 首领战 |
| --- | --- | --- |
| 1 月面基地 | 星际补给兵在飞机上方画弧线。进入月面后，斜切编队、弹跳机械兔与地炮交替出现。中段的浮空球会追飞机，可以先把它引开再绕回下方。 | 炮口先把胡萝卜向两侧射出，弹体再弯向飞机。睁眼时打眼，每边有独立耐久，击破对应的一侧会停火。 |
| 2 熔岩火山 | 穿过熔岩沟，在俯冲导弹和会炸开的火球中换位。中段炮台的导弹可以打掉。 | 火山守卫居中蓄势后下冲。提前侧移躲冲锋，避开两颗球炸出的斜向弹。 |
| 3 海上舰队 | 水泡圈标出鱼的入场位置。长船的船腹装着补给，中段海妖从双手射出会拢回来的水泡。 | 章鱼浮出时才能伤到本体。下潜时触手各自出水、计分，下一次出现的位置有水纹。 |
| 4 深林树冠 | 蓝橡果会原地爆散，提前击落能保住走廊。中段巨橡果把弹丸向上抛，从高处落回。 | 树精的长枝伸向飞机后方，再拖着一排弹收回。留出侧方路线，可以绕开枝尖和身后的子弹。 |
| 5 金钱世界 | 钱袋收入钱包，飞来的金币会伤人。壳状敌人展开时才受击。招财猫周围的金币会向内回收。 | 黄金机械像从两侧放弧线弹，预告地砖翻起的位置后，再从那里射出碎片。 |
| 6 陶土遗迹 | 箭头敌机会分出追踪弹。陶偶移动时挡枪，停下后蓄力，再沿同一列向上、向下打出激光。 | 石像轮流从沙坑探身，露出时会喷碎石。看下一个沙坑的尘圈，等它完全出现再开火。 |
| 7 太阳表面 | 太阳在侧缘交替出现，火流先预告再横扫。后段有平行火流，中间保留可飞的空档。全区连续飞行。 | 弯月首领不断移动，可以打掉它发出的月牙，在弹群中打开通路。 |
| 8 太阳内部 | 机械要塞的光束会直角转弯。依次再战浮空球、巨橡果、重炮台。最后一次补给可把钱换成炸弹。 | 地面砖块破开后，异兽从地下突袭。第二阶段的核心向内折射激光，大泡落底后向上散开。打完直接进入结局。 |
| 0 隐藏星域 | 机库「飞行设置」把声音测试调到 05，再把出发地区调到 0。沿深蓝星空穿过侧击、追踪弹和从后方入场的编队。 | 陶偶在战场下半部巡游。等它打完纵向激光，从下方攻击。通过补给站后飞往第 1 区。 |

## 操作与补给

| 动作 | Xbox 标准布局（优先） | 键盘 |
| --- | --- | --- |
| 移动 | 左摇杆（平滑） / 方向键 | WASD / 方向键 |
| 自动射击 | 默认连射，无需按键 | 默认连射，无需按键 |
| 投弹 | A | K |
| 四档机速 | Y / View / RB 升档，LB 降档 | L 循环 |
| 暂停 / 恢复 | Menu（暂停页 B 也可恢复） | Enter / Esc |
| 菜单选择和确定 | 摇杆 / 方向键、A 确定、B 返回；LB / RB 逐项移动 | WASD / 方向键、J / Enter 确定、Esc 返回 |
| 调整设置数值 | 摇杆或方向键左右 | A / D 或左右方向键 |

五种枪按说明书各有短板：1 号散射低伤，2 号爆破单发最重，3 号小月牙会追但伤害低、打中就消失、不劈敌弹，4 号火龙跟随机体并越飞越短，5 号宽光束穿透且等级越高空隙越大。新局和续关都从 1 号 1 级、3 条命起飞，不再先选武器卡，每关开局也不再白送 1～5 号。同号升级，换一种枪保留当前等级；没有机翼最高 3 级，有机翼最高 8 级。玩家机体是彩笔小战斗机，战场上裸机约 16×16，装上机翼约 26×16。机翼少见，拿到后小飞机变大并能挡一次；再被打中只卸翼并把等级回到 1。没有机翼时扣一条命、钱减半、主炮回到 1 号 1 级。击落和中段补给以钱袋和升级芯片为主，大约每十几个才一只机翼。第 0～8 区与首领战各自配有不同调式、配器、速度与 64 步旋律的专属背景音乐。F 火环留在投放处，B 冰壁横扫，T 雷电随飞机位置改变折射，W 水弹升起后延迟落下。

补给站用 ¥10 换枪或装机翼，¥6 加一级连射，¥4 向后续指定区域预送炸弹。出发时一次入库，上限 20 枚。终关补给按每 ¥10 一枚兑换，弹仓满后保留余款。从本区续关会重置本区路线，命数回到 3，主炮回到 1 号 1 级，连射保留，待送炸弹减半。

地图、编队、首领与输入在 JavaScript 中以固定 60 步每秒运行。Three.js 在固定的 4∶3 战场（256×240）里绘制原创彩笔素材；宽屏左右侧栏承载 HUD，战场不再随窗口拉宽。音乐与打击声由本地 Web Audio 合成。飞行场景和商店使用单独的本机存档。切走窗口或手柄断开会暂停，回到游戏后需要主动继续。
