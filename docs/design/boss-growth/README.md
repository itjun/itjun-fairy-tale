# BOSS 战与生命成长

用户已确认按推荐组合开发：前两关采用开阔教学场地，后续以高低平台战为主，大关加入踩机关破盾。保留女儿原画角色、彩笔素材和移动、跳跃、攻击三类操作。

## 关卡与奖励

24 个小关各有一位 BOSS，8 个世界各另有一位大关 BOSS，共 32 场。每个世界的第三小关先打小关 BOSS，再打大关 BOSS，最后集中结算。入口触发战斗后限制在场内活动，打赢才放行；无法绕过 BOSS 直接通关。

| --- | --- | --- |
| 彩虹花园 | 果冻队长、云朵领航员、花丘守卫 | 彩虹花王 |
| 家人小镇 | 街巷哨兵、屋顶跳跳王、铃铛队长 | 钟楼守卫 |
| 甜甜城堡 | 糖球队长、饼干卫士、奶油蘑菇 | 布丁国王 |
| 贝壳海边 | 沙堡卫士、泡泡鱼王、浪花蟹队长 | 贝壳蟹王 |
| 风车草地 | 叶盾队长、松果投手、疾风萤火 | 风车守卫 |
| 雪人乐园 | 雪球队长、冰花卫士、冰锥守卫 | 雪人国王 |

BOSS 会主动接近玩家，近身后退开；蓄力时停下并标出锁定位置，首次约 3 秒后施放，攻击前至少预告 2 秒。技能按玩家高度和距离计算弹道，地面和高台都有威胁，预告后离开目标位置可以躲避。大关 BOSS 半血进入第二阶段；护盾减伤 30%，踩地面星星机关可打开 12 秒，按有效游玩时间计算。小关与大关攻击均扣 1 点生命。

小关通关给 6 片基础碎片和三选一；大关给 12 片基础碎片、生命上限 +1、攻击 +10%，再四选二。已有资源技能可增加少量碎片。奖励初始不选中，选满后明确确认领取；空格或攻击键不会误选。已领取的奖励不能再次领取。

## 数值与成长

删除体力，只保留一条生命资源：新冒险初始 9 点，受伤直接扣生命，零生命结束冒险；药瓶可以补生命。每收集 4 件宝物材料，生命上限和当前生命 +1，所有武器攻击 +10%。奖励另可选择生命上限 +2 或攻击 +20%。这些成长只在本次冒险持续，跨关、暂停和保存恢复保留。

| 武器 | 基础伤害 | 发射间隔 | 打法 |
| --- | --- | --- | --- |
| 贯穿光刃 | 30 | 0.4 秒 | 穿过平台和沿途目标，每道对同一目标一次 |
| 圆月弯刀 | 48 | 0.18 秒 | 自动追踪，每把对同一目标一次 |
| 魔法泡泡 | 55 | 0.75 秒 | 命中后范围爆开 |
| 彩虹星雨 | 32 | 0.65 秒 | 基础一颗，探索中叠加散射数量 |
| 回旋星镖 | 去程 34、回程 34 | 0.8 秒 | 来回各一次命中 |
| 花种弹 | 72 | 1 秒 | 抛射，命中或落地范围开花 |

实际伤害按成长加成取整；显示 BOSS 当前/最大生命、实际扣血和护盾减伤。玩家生命条会随生命上限逐渐加长，HUD 同时显示攻击加成、材料进度和各武器实际伤害。多个武器与技能叠加，限时道具只消耗有效游玩时间。

## 保存兼容与验证

新关使用地图版本 5；版本 1～4 的已有局保持原地图，下一关或新冒险进入新版。旧生命存档保留剩余生命，首次升级覆盖前保存备份。生成地形与敌人静态信息不从存档覆盖；BOSS 血量、阶段、护盾剩余时间与成长经过校验后恢复。

115 项自动测试通过，包含 32 场 BOSS、真实武器伤害、护盾/阶段、成长、奖励领取防重、旧档兼容、无法绕过首领，以及 72 张新版地图的完整物理路线。浏览器用隔离档验证破盾、多武器伤害、四选二、跨关成长、真实拾取和刷新恢复；Windows 和儿童实际难度仍待试玩验证。桌面安装结果见根目录验收报告。


## 主动技能反馈（2026-11-13）

用户要求每个 BOSS 都释放自己的技能攻击玩家，不能站着挨打。此前固定高度弹道存在高台盲区，首次出招约 3.7 秒且多数首领不走动；本次增加主动距离调整、目标锁定、明显蓄力与主题弹道。

| 世界 | 三项主题技能 |
| --- | --- |
| 彩虹花园 | 花瓣散射、彩虹跳跳球、花藤冒芽 |
| 家人小镇 | 铃铛音浪、钟摆冲锋、铃铛落雨 |
| 甜甜城堡 | 糖球弹跳、糖果抛投、奶油冒泡 |
| 贝壳海边 | 浪花追击、贝壳抛投、蟹钳冲锋 |
| 风车草地 | 回旋叶刃、花种散射、旋风追击 |
| 雪人乐园 | 冰锥落雨、雪球连跳、霜花散射 |
| 蘑菇森林 | 树根追踪、蘑菇孢子、飞叶回旋 |
| 卡通梦工场 | 飞星光波、积木落雨、发条冲锋 |

每位小首领以对应章节的一招为主并轮换第二招；大首领组合三招。回旋弹道来回飞行，抛射按锁定目标计算弧线，树根可在目标平台冒出，冲锋同时甩出主题弹道。第二阶段提高移动速度与弹速、缩短招式间隔，保留完整预告。

HUD 显示正在准备或施放的技能；角色附近显示落点提示，敌方弹道使用主题彩笔素材。暂停冻结招式，锁定目标高度随存档恢复；击败 BOSS 立即清除其残留技能。新检查覆盖所有 32 场首领在地面/高台的伤害与位移，以及可躲避、暂停、存档目标恢复和残留攻击清理。

## 儿童难度调整（2026-11-13）

用户反馈单武器输出低、BOSS 血量过多。提高所有武器基础伤害，弯刀由 16 提至 48、间隔由 1.2 秒缩短至 0.75 秒；保留开局一种武器、一枚弹道和探索叠加成长。24 位小关 BOSS 的生命为 180～732，8 位大关 BOSS 为 480～1180；降低护盾减伤并延长开盾时间，出招间隔更宽、弹速和冲锋放慢。BOSS 血条高度缩至 10px，当前/最大生命数字继续显示。

已有版本 5 存档按剩余生命比例迁移 BOSS 血量，死亡状态保留，首次覆盖旧序列化存档前备份；保存最大生命以避免重复迁移。地图、玩家生命与构筑不重置。全 32 场真实引擎模拟使用无强化单弯刀、不走位、不踩机关：2.97～25.77 秒击败，最少剩余 4/9 生命。模拟不替代儿童试玩，浏览器与本机构建结果见根目录验收报告最新记录。
