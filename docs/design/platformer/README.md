# 上下路线与小怪

2026-11-09，用户选定三张设计稿全部实现，按不同关卡使用不同路线。三张源图为 rainbow.png、forest.png、cave.png；均由内置 ImageGen 生成，参考现有游戏截图、原画和粉裙小女孩素材。没有重新命名已有游戏或关卡。

| 路线 | 关卡 | 行为 |
| --- | --- | --- |
| 阶梯分层 | 彩虹花园、家人小镇、风车草地 | 地面与高处路线并行，阶梯上升、桥面横穿、台阶下降，中层可下跳 |
| 树屋回环 | 蘑菇森林、卡通梦工场 | 叶台升降至中层，向左登高，再沿上层向右绕回地面 |
| 地下探险 | 甜甜城堡、贝壳海边、雪人乐园 | 洞口下降、地下宝物、中间台与弹簧花、阶梯返回地面 |

保持原角色、手写字体、纸张按钮、无限生命、不限时和旧成绩。采用横向滚动的实际关卡视野，镜头随人物适度上下移动；源图的全景用于确定层次、路线、素材和配色，不把静态全景直接作为游戏背景。

宝物编号仍为 1 到原关卡宝物总数，计分版本仍为 2。新地形拥有独立编号；小怪不计入宝物分数。服务端仍按种子和拾取编号算分，历史数据无需迁移。

新增素材由内置 ImageGen 独立生成，保存于 public/assets/：

- enemy-jelly / enemy-leaf / enemy-puff：透明背景，正面彩笔小怪，粉果冻、绿叶子、青蓝飞行绒球，友善表情，粗糙深蓝轮廓；无文字或背景。
- lift-leaf：宽而平的绿色叶子，薄纸片厚度；spring-flower：可站立的粉花黄花心与短茎；均透明背景。
- cave-paper：1600×600 明亮青蓝与淡紫洞穴纸纹，中央留白，下沿圆润小石头；无人物、平台、宝物或 UI。
- landscape-rainbow / landscape-forest / landscape-sweet：1600×900 稀疏彩笔远景，保留原城堡和树屋风格，画面中央留白，装饰集中边缘，不含可玩平台与宝物。
- bridge-rope / checkpoint-flag：透明彩笔木桥及粉色星星旗，作为桥面和终点的视觉标记。

生成后仅修整透明边距、等比缩小素材，不用代码重画插图。实际玩法验收与截图记录见项目根目录 design-qa.md。
