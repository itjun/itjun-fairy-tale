## 平台怎么摆

- 一层高 2.4。人一次能跳 3.4 高，所以上一层一定跳得上去。
- 两块平台只要左右有重叠，上下至少差一层。
- 同一层的两块平台，要么接成一整块地面，要么中间留出至少 1.1 的缝。
- 移动的台子按它走过的整段路来算位置，别的平台不许伸进这段路里。
- 放不下就换一层，再放不下就不放。这条规则有测试，八个世界各抽多个种子检查。
- 叠在别的落脚面上方、相差不到两层的平台，贴图最厚画 0.9，下面留出 1.5。普通小怪和宝物放得进去。四位家人都比 1.5 高（画出来妹妹顶到 1.77，爸爸顶到 2.46），从这种平台底下走过时，头画在上层平台前面，不会被挡住。

## 五种房型

开场房和机关房从这五种里挑，同一章里相邻两间不重复。每种房型里都嵌一段这个世界自己的机关（弹簧、钟摆、开关桥、木筏、跷跷板、冰面、树干升降、传送带）。门是传送，所以出口可以在高处，也可以在低处。

| 房型 | 怎么走 | 看点 |
| --- | --- | --- |
| 上山下山 | 三级台阶上去，过山顶，再下来 | 山顶一处陷阱 |
| 上下两层 | 下层走地面，上层走窄台子 | 下层有坑和陷阱，上层有宝物，两头和中间能换层 |
| 往上爬的竖井 | 左右交错的台子，加一部升降台 | 门在最高处，掉下去落回井底，不扣血 |
| 往下跳的洞 | 从高处出发，一层层往下落 | 洞里有会飞的怪 |
| 坑上过河 | 左右移动的台子接会塌的平台 | 中间一块安全落脚点 |

## 其他房间

- 战斗房、精英房的场地三选一：中间有坑两边高台；三层看台；中间一部升降台，两边各一块最高的台子。
- 宝箱房和小店：进门先上或先下一两级台阶，谜题和摊位在另一层。不放陷阱。
- 首领房：按 2026-11-16 反馈改为八块跳台、三层高度，每层相差 2.4，左右和中间都能从地面连续跳上去换层躲招。不加陷阱，首领的招式已经盖住地面和高台。
- 出口门统一放在通关旗前方；两扇门时，低门在出口地面，高门由两级跳台接上。新版地图保留门在尽头的高低布局；第 10 版及更早的进行中冒险按用户授权清除。

## 陷阱和障碍

- 带节拍的陷阱沿用现有四种，按世界挑：刺、蒸汽或喷泉、钟摆、冰柱。出手前都有预告。
- 新增不动的障碍：刺丛或积木堆，一直在原地，要跳过去，碰到扣血。
- 数量：开场房 2～3 处，机关房 4～6 处，战斗房和精英房从第二层门起在后两个战区各放 1 处。
- 摆放规则：起点、出口和门前不放；离平台边至少 3；两处之间至少隔 6；两处带节拍的陷阱之间一定隔着一块没有陷阱的平台。

## 怪

- 按位置摆：会射的站高台，会飞的守坑和竖井，会冲的放长平地，会跳的放台阶。
- 数量：开场房 8～10 只，机关房 12～18 只，战斗房 18～24 只，精英房 12～18 只；战斗及精英房分三战区、每区两波。离起点 6 以内不放。
- 每个世界的怪物池是 11 种。纸飞机、气球、章鱼、企鹅、双胞胎、蒲公英这六种原先只在旧地图里出场，现在并进来，三十种怪都遇得到。企鹅这类硬壳怪要先打掉壳。
- 同屏主动出手的仍然最多 3 只。

## 难度

三档都用新地形。轻松档仍然受伤减半、预告更久、掉坑不扣血，默认还是轻松。
