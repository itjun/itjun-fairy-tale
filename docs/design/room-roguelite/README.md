# 选门闯房间与全手柄改版

2026-11-15。用户选了两个方向：一章拆成几间一分钟左右的小房间，过完一间在两扇门里挑一扇；局外用画册收集代替数值成长。整套应用要能只用 Xbox 手柄玩完。

## 设计稿

- [选门](door-choice.jpg)：房间清完，两扇门打开。门上只写“进门”，不写后面是什么房间、给什么奖励。走到门前按上进门，不弹菜单。
- [房间里的界面](room-hud.jpg)：左上命数和血条，上方中间是这一章的房间进度，右上是碎片和连击，右下是 A、X、Y 三个键。大招攒满时 Y 发光。
- [画册](album.jpg)：一页一幅原画，分成六块，拿到贴纸点亮一块。集满一页解锁右边写的东西。LB、RB 翻页。
- [选项页](options.jpg)：左边分类，右边是这一类的选项，底部是按键提示条。

四张图由内置 Image Gen 生成，参考了 `public/artworks/7.jpg` 和已确认的 `docs/design/roguelite-map-redesign/branching-rooms.png`。图里的文字、数字和缩略图只表示位置。实机用本地手写字体、真实的彩笔素材和 `public/slideshow/` 里的 11 幅原画，不拿效果稿当验收。

## 一章怎么走

一章是 4 间房加一场首领，对应一个世界，八个世界就是八章。

1. 第一间固定，用来熟悉这个世界的机关。
2. 第二、三、四间各有两间候选，种子随机决定后面是什么。上一间清完后两扇门打开，两扇门长得一样，不告诉玩家后面是小店还是战斗。进去之后，该给的奖励照给，小店照常花碎片。
3. 第四间只有一扇门，通向首领。

房间种类：

| 种类 | 怎么过 | 备注 |
| --- | --- | --- |
| 战斗房 | 门先关上，打完 2 到 3 波怪 | 挑战难度多一波 |
| 机关房 | 用这个世界的机关走到出口 | 每个世界自己的那一条机关 |
| 宝箱房 | 没有怪，解一个小谜题 | 按顺序踩彩虹砖、翻牌配对、找三颗星星钥匙 |
| 小店 | 用彩笔碎片换东西 | 回血、随机本领、重抽券、升一档 |
| 精英房 | 一只带特点的大怪加几只小怪 | 第三个世界起出现，奖励高一档 |
| 首领房 | 打赢首领 | 两段招式，放完招有破绽 |

门上的奖励有六种：武器、本领、大招、爱心、碎片、画册贴纸。前三种在清完那间房后弹三选一，要先点选再确认。后三种直接掉在门边，走过去就拿到。

一章里选卡只出现两次：中间那一层的门（这一层有精英房就只给精英房），加上打赢首领。开场房不给，最后一间门前也不弹，免得进门前领一份、打完再领一份。小怪补给一章最多一份，打倒十几只才会掉，不会打两下就弹出来。

种子决定每扇门后面是什么房、给什么奖励、落脚点和怪物。暂停、掉坑、退出再进来都不重抽。

## 奖励

- 本领分力量、泡泡、飞行、冰霜、自然五系。同系凑够 3 个触发套装效果，5 个加强。暂停页的“本领一览”写着每系有几个。
- 首领保底一张传奇，精英房保底一张史诗，普通门按概率出普通、稀有、史诗。这条替代“每个小关保底传奇”。
- 3 秒内连续打倒怪算连击，每连 3 只给 1 片碎片。跳过奖励也给碎片。碎片只有一个数，在小店花。
- 每间房三颗星：清完、没掉血、没掉坑。星星只用来换画册贴纸，不改积分。

## 怪物和首领

- 每间房按“预算”配怪，世界越靠后预算越多。同屏主动的仍然不超过 3 只。
- 精英有四种特点，头顶有牌子：大个子、带盾、会分身、跑得快。
- 首领前半段只用一招。打到半血加第二招。每放完一招有 1.5 秒破绽，这时打中伤害翻倍。

## 难度

出发前选，路上不能改。默认轻松。

| 档位 | 区别 |
| --- | --- |
| 轻松 | 受伤减半，预告多 0.6 秒，掉坑不扣血 |
| 标准 | 现在的数值 |
| 挑战 | 战斗房多一波，最后一波混进一只精英，高品质奖励更容易出 |

“帮一把”默认打开：同一间房里倒下两次，再起来时送一层护盾，不弹窗。

## 大招

打中怪才攒能量。攒满后 Y 的图标发光，按 Y 放。选项里的“满了自动放”默认打开，打开时攒满后继续攻击就会放出去。

## 画册

- 11 页对应 11 幅原画，每页 6 块，共 66 块。
- 贴纸来源：第一次打赢每个世界的首领、第一次打赢每个世界的精英、解开宝箱房、每攒 9 颗房间星、同一种怪打倒 10 只。
- 集满一页解锁新东西，不加数值。四把武器（火龙、星镖、花种、萤火）、两种大招、十二个本领和新的花园贴纸都放在画册里。
- 升级那一刻存档里已经有的武器和本领直接算解锁。
- 画册存在本机，花园备份升到第 3 版，仍能读第 1、2 版。

## 手柄

| 键 | 游玩中 | 页面上 |
| --- | --- | --- |
| 左摇杆、方向键 | 移动；下加 A 下跳；门前按上进门 | 移动色块 |
| A | 跳，空中再跳一次 | 确定 |
| B | 不暂停 | 关掉当前这一层；必须选的弹窗里不起作用 |
| X、RT | 攻击 | |
| Y | 放大招 | |
| LB、RB | | 翻页、换分类、换难度 |
| View | 看这一局的本领和这一章的门 | |
| Menu | 暂停 | 继续 |

每个页面底部有一条按键提示，只在用手柄时出现。文案跟着输入方式换，手柄时写“按 A”。

页面改动：

- 主菜单：继续冒险、新冒险、画册、小游戏、选项。
- 出发：选世界的那一页用 LB、RB 换难度，再进角色营地。
- 暂停：继续、本领一览、选项、回花园。
- 选项：游戏、手柄、窗口、作品与成绩、存档五类。
- 不再弹系统窗口。保存失败改成应用里的确认页；备份写到固定的备份文件夹，恢复时从应用里的列表挑。托盘菜单留给鼠标。
- 成绩本的曲线用 LB、RB 一个点一个点看，日期只留今天、7 天、30 天、全部。

## 这一轮不做

找不同、连连看这类独立小游戏只做成宝箱房里的小谜题。冲刺、闪避和改键不做。
