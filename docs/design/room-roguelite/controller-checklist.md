# 实体手柄试玩清单

2026-11-16 更新。测试时这台电脑没有接实体手柄，下面两部分要分开看。

## 菜单导航修复

- 普通菜单已经高亮的选项，按一次 A 就确认；不再要求额外按一次来同步内部状态。暂停继续、返回后再打开装备、通关去下一关均有桌面回归。
- 结算默认聚焦“去下一关”，不再聚焦会随保存完成而消失的“重试保存”。奖励、补给、死亡弹窗仍不默认选卡，跨页和重连仍须先松开按键。
- 测试先让 Electron 真正获得焦点，按键等待实际轮询采样；失焦自动暂停的产品行为保留。失败时输出焦点、页面和采样记录，并在隔离目录保存截图。
- 导航测试用方向键走到控件，再按 A；不通过鼠标点击或直接修改焦点完成操作。`GARDEN_GAMEPAD_CASE=completion npm run test:gamepad` 可单独复现通关焦点问题。

## 模拟输入已经跑过

`npm run test:gamepad` 在真的 Electron 窗口里塞进一个假的 Xbox 标准手柄，用隔离目录，不碰家里的存档。它确认了这些：

- 主菜单、选世界（包含滚动到第八个世界）、换难度（LB、RB）、角色营地、换出发装备、角色试用和返回。
- 游玩中摇杆移动、A 跳、B 不暂停、View 打开本领一览、Menu 暂停和继续。
- 暂停里进本领一览和选项，B 一层一层退回来。
- 能进的门会发光，没有“进门”两个字。没跳到门上时，连按 A、X 不会进门。跳到发光的门上就进去。
- 摇杆走到低门会进入下一间；小店站到回血摊位前按上购买，扣碎片并恢复 50 点血。
- 手柄断开、窗口失焦会暂停；按着键重新连上不会自己继续。
- 选项里换分类、调摇杆死区、进入和退出全屏；存档分类里备份一份、恢复一份。
- 成绩本切换关卡、时间范围与曲线类型，LB、RB 查看曲线点；原画翻页、成就返回、画册翻页。
- 三个小游戏全部 29 个任务（其中甜蜜分享有 12 份订单）、完成页、重玩、提示、放置与撤回；花园贴纸。
- 奖励、补给、倒下、命数用完这四种弹窗，按住键都不会误选。
- 零命后重来；打赢首领后领取奖励、结算，按一次 A 进入下一关，保留角色。

本轮 `npm run test:gamepad` 已完整通过，读取到的实体设备列表为空。199 项功能测试通过；性能与桌面测试分开运行时，后期战斗单步耗时 p95 为 0.35 毫秒，低于 4 毫秒门槛。并行跑桌面测试时曾出现耗时超标，不放宽性能门槛。

`npm run desktop:test` 也通过：真实关闭并重新打开 Electron 后，成绩、冒险以及三个小游戏盘面仍然保留；这部分使用常规桌面测试输入，与上面的模拟手柄验证分开记录。

假手柄测不出来的：真手柄的按键编号、摇杆回中有没有漂、蓝牙延迟、震动、孩子的手感。

## 要拿真手柄试的

每一项分别用 USB 线和蓝牙各试一遍，Mac 和家里的 Windows 电脑各试一遍。哪一项不对，记下系统、连接方式和手柄型号。

连接

- [ ] 先开游戏再接手柄，窗口顶上出现“手柄已连接”。
- [ ] 先接手柄再开游戏，按一下 A 唤醒，不碰键盘鼠标就能从主菜单开始。
- [ ] 玩到一半拔线或关掉手柄，游戏暂停；接回去后要自己按 Menu 才继续。
- [ ] 选项里的手柄分类能看到手柄名字。手柄不是 Xbox 布局时有提示。

页面

- [ ] 主菜单五项都能用摇杆走到，色块是整块填色。
- [ ] 每一页底部的按键提示和真手柄上的键对得上（A、B、X、Y、LB、RB、View、Menu）。
- [ ] B 在每一页都只退一层。奖励弹窗和倒下弹窗里按 B 没反应。
- [ ] 选项的窗口分类里，全屏、重新启动、退出都能用手柄点。
- [ ] 存档分类里备份一份，再从列表里恢复，全程不弹系统窗口。
- [ ] 成绩本用 LB、RB 一个点一个点看曲线。

闯房间

- [ ] 开场房走到出口不弹选卡；中间奖励房和首领战后才选，先选一张，再按确定。
- [ ] 两扇门一高一低，发光，不写字，看不出后面是小店还是别的。跳到门上就进去。
- [ ] 战斗房打完一波出下一波，顶上的字跟着变；打怪计分，碎片按房间奖励结算。
- [ ] 宝箱房三种谜题各遇到一次：踩彩虹砖、翻牌配对、找三颗星星钥匙。
- [ ] 小店里站到摊位前推上买东西，买过的写“卖完了”，碎片不够有提示。
- [ ] 拿到大招后右下角出现 Y。打中怪攒满时 Y 发光，按 Y 放出去。
- [ ] 选项里把“大招满了自动放”关掉，攒满后不按 Y 就不放。
- [ ] 首领放完一招，血条上写“露出破绽了”，这时打得更疼。
- [ ] 打赢首领走到终点，选完奖励按“去下一关”直接进下一个世界。
- [ ] 玩到一半按 Menu 回花园，再点“继续冒险”，回到同一间房，门和奖励没变。

手感（请孩子来试）

- [ ] 轻松档能不能顺利打完第一个世界。哪一间房卡住了，卡了几次。
- [ ] 一间房大约多久。设计是一分钟上下。
- [ ] 没站到发光的门上时，跳和攻击不会把人送进下一间。
- [ ] 首领的预告看不看得懂，破绽的 1.5 秒够不够。
- [ ] 同一间房倒下两次后送的护盾，孩子有没有注意到。
- [ ] 震动的强弱合不合适。

数值按试玩结果再调，主要是每间房的怪物预算、首领血量和破绽时长。
