# 实体手柄试玩清单

2026-11-15。开发时这台电脑没有接手柄，下面两部分要分开看。

## 模拟输入已经跑过

`npm run test:gamepad` 在真的 Electron 窗口里塞进一个假的 Xbox 标准手柄，用隔离目录，不碰家里的存档。它确认了这些：

- 主菜单、选世界、换难度（LB、RB）、角色营地、换出发装备。
- 游玩中摇杆移动、A 跳、B 不暂停、View 打开本领一览、Menu 暂停和继续。
- 暂停里进本领一览和选项，B 一层一层退回来。
- 门前出现“往上推”的提示；连按 A、X 不会进门，推一下摇杆才进。
- 手柄断开、窗口失焦会暂停；按着键重新连上不会自己继续。
- 选项里换分类、调摇杆死区；存档分类里备份一份、恢复一份。
- 画册用 LB、RB 翻页。三个小游戏和花园贴纸。
- 奖励、补给、倒下、命数用完这四种弹窗，按住键都不会误选。

假手柄测不出来的：真手柄的按键编号、摇杆回中有没有漂、蓝牙延迟、震动、孩子的手感。

## 要拿真手柄试的

每一项分别用 USB 线和蓝牙各试一遍，Mac 和家里的 Windows 电脑各试一遍。哪一项不对，记下系统、连接方式和手柄型号。

连接

- [ ] 先开游戏再接手柄，窗口顶上出现“手柄已连接”。
- [ ] 先接手柄再开游戏，按一下 A 唤醒，不碰键盘鼠标就能从主菜单开始。
- [ ] 玩到一半拔线或关掉手柄，游戏暂停；接回去后要自己按 Menu 才继续。
- [ ] 选项里的手柄分类能看到手柄名字。手柄不是 Xbox 布局时有提示。

页面

- [ ] 主菜单五项都能用摇杆走到，色块是整块填色。
- [ ] 每一页底部的按键提示和真手柄上的键对得上（A、B、X、Y、LB、RB、View、Menu）。
- [ ] B 在每一页都只退一层。奖励弹窗和倒下弹窗里按 B 没反应。
- [ ] 选项的窗口分类里，全屏、重新启动、退出都能用手柄点。
- [ ] 存档分类里备份一份，再从列表里恢复，全程不弹系统窗口。
- [ ] 成绩本用 LB、RB 一个点一个点看曲线。

闯房间

- [ ] 开场房走到出口，稍等弹出三选一。先选一张，再按确定。
- [ ] 两扇门都只写“进门”，看不出后面是小店还是别的。站到门前推摇杆向上进门，方向键的上也行。
- [ ] 战斗房打完一波出下一波，顶上的字跟着变。连着打倒三只，碎片加一。
- [ ] 宝箱房三种谜题各遇到一次：踩彩虹砖、翻牌配对、找三颗星星钥匙。
- [ ] 小店里站到摊位前推上买东西，买过的写“卖完了”，碎片不够有提示。
- [ ] 拿到大招后右下角出现 Y。打中怪攒满时 Y 发光，按 Y 放出去。
- [ ] 选项里把“大招满了自动放”关掉，攒满后不按 Y 就不放。
- [ ] 首领放完一招，血条上写“露出破绽了”，这时打得更疼。
- [ ] 打赢首领走到终点，选完奖励按“去下一关”直接进下一个世界。
- [ ] 玩到一半按 Menu 回花园，再点“继续冒险”，回到同一间房，门和奖励没变。

手感（请孩子来试）

- [ ] 轻松档能不能顺利打完第一个世界。哪一间房卡住了，卡了几次。
- [ ] 一间房大约多久。设计是一分钟上下。
- [ ] 推摇杆进门会不会误触。跳的时候摇杆稍微偏上有没有被当成进门。
- [ ] 首领的预告看不看得懂，破绽的 1.5 秒够不够。
- [ ] 同一间房倒下两次后送的护盾，孩子有没有注意到。
- [ ] 震动的强弱合不合适。

数值按试玩结果再调，主要是每间房的怪物预算、首领血量和破绽时长。
