# 游戏框架与轮回实测说明

2026-11-17。用户要求实际运行测试，并用互动 HTML 说明角色、武器、道具、首领、小怪、玩法与限制，同时要求每个轮回自动提高难度。

## 轮回规则

跨轮保留本次角色与成长，敌人逐轮增强。通关最后一个世界（当前为沙漠绿洲）后点击“进入第 N 轮”跨轮，选关仍允许从任一世界开始。新冒险和死亡后“重来”从第一轮开始，死亡“继续”及刷新停在本轮。

每轮保留本次角色、武器、本领、品质、大招、资源、命数、当前血量和限时效果；下一世界用新种子生成。首领、护甲、召唤和精英的基础生命每轮线性增加 20%，敌人碰撞与弹道伤害每轮线性增加 12%。普通小怪生命不增加，预告、同屏主动上限、陷阱和掉坑规则保持。数值是本次实现的起点，尚未经儿童试玩校准。

地图仍为第 11 版。旧第 11 版无轮数字段的冒险按第一轮恢复；不改变原种子、平台、门、敌人编号和历史积分。首领装备加厚上限 1.8 倍，以当前轮的基础生命为基准，读档保留已经扣掉的生命。

## 在本地生成互动报告

- 运行 `node docs/design/game-framework/probe.mjs`，生成引擎战斗和房间规模的 `probe-results.json`。
- 再运行 `node docs/design/game-framework/build-report.mjs`，生成可离线打开的 `index.html`。报告从当前代码读取图鉴；如同目录有本地实测截图 `cycle-2.webp`，也会加入报告。

## 2026-11-17 的验证

- `npm run build` 通过；随后 `npm test` 的 207 项功能检查和 1 项性能检查通过，包含 Sites 输出校验。曾并行运行构建与测试，构建清空 dist 时造成两项产物检查失败；构建完成后顺序运行全套均通过。
- 48 场实际 GardenEngine 自动战斗：八世界 × 第 1～3 轮 × 基础弯刀／八武器叠加，全部击败首领且各至少出招三轮。基础弯刀第 1 轮 14～14.68 秒，第 2 轮 14.41～15.96 秒，第 3 轮 15.07～17.72 秒；叠加组各轮 12.52～12.61 秒。探针操作、配置和明细在 JSON 中，不代表儿童通关用时。
- 320 个种子世界、2560 个候选房间规模统计：开场 11～13、机关 15～21、战斗 21～27、精英 17～21 只，不含挑战额外波、召唤子怪和首领。
- 浏览器四角色营地切换与推荐搭配、键盘移动／跳跃／攻击／暂停通过。使用隔离结算场景测试第八世界跨轮：第 2 轮保留三把武器、140/160 血、3 命、27 碎片，彩虹首领基础生命 1440，刷新恢复一致。
- `npm run test:gamepad` 通过：macOS Electron，独立用户目录，模拟 Xbox 输入；菜单、营地、三个小游戏全部题目与重玩、画册、画展、备份恢复、奖励、补给、死亡、进门、小店、结算与下一关。实际检测到的实体手柄列表为空。
- HTML 九个章节、角色／武器切换、本领搜索、怪物分类、轮回数值和战斗轮次切换通过；390 像素宽度逐章检查无横向溢出，明暗主题已查看。
- 未验证实体 Xbox 的 USB／蓝牙连接、Windows、儿童试玩、人工连续打通完整八世界或上百轮耐久性。本次没有替换 /Applications 的安装版本，也未提交、推送或发布。

## 检查中保留的已知限制

- 节约巧手、探路奖励未接入当前小店／选门结算，仍可能在候选池出现；重复变宝保留执行分支，但现行奖励池不会生成对应回收卡。
- 三种限时道具已有执行与存档能力，但当前门奖励池没有投放入口。
- 基础火龙伤害 18，冲锋怪生命 20，因此“普通怪一击”并非所有基础武器的无条件结论。
- 轮回增加敌人强度，但成长过快仍可抵消压力；叠满武器的交战时长主要由首领承伤上限决定。尚未验证超长冒险的资源计数、事件列表存档上限。
