每张新版稿的上、下半部分是先后出现的两张整页。新冒险在地图上按 A 进入选角页，选好家人按 A 直接出发。选角页按 B 回地图，焦点回到刚选的世界。续玩沿用存档中的角色和落脚点。选角页按 Y 可为当前家人打开「出发设置」，改搭配、试用或调难度。返回后焦点仍在这位家人身上。

地图是一张连贯的山河画。北方的雪人与雪岭、南方的雨林与猫头鹰、东面的贝壳海岸与灯塔小岛、西部的敦煌石窟与防风林，以及四川盆地里向东流的河，都与现有世界入口对应。横屏和竖屏各有一幅插画，地标按各自画面定位。选图只改变冒险入口，用原关卡标识读取各局的角色、地图和落脚点。

## 三稿共用的交互提案

- **字要能从沙发上看清。** 以 1280 × 720 为基准，标题约 36–44 px，用本地霞鹜文楷。动作标签约 24–28 px，提示约 20–22 px，用笔画清楚的中文常规字。文字放在干净纸面上。出发按钮首屏可见；手柄焦点用整块填色配合勾或箭头。
- **提示跟着动作出现。** 第一次靠近水槽时，在水槽旁显示「站上水槽」；完成后收起。需要按键时只显示当前输入设备的一种按法。首领落点等紧急提示优先。试用、难度和初始搭配从「出发设置」进入。
- **继续时认得是哪一局。** 已有进度显示世界、角色和「接着玩」；同一世界有多份进度时再列出角色与所在段落。续玩直接回到原状态，要求主动领取奖励或选择复活的进度仍停在对应的选择。新冒险沿用独立存档。
- **返回说清目的地。** 战斗用 Menu、Esc 或画面的暂停键打开菜单，初始焦点在「继续玩」。B 在普通菜单退一层，战斗中仍是玩家绑定的攻击。「换世界」和「回花园」保存成功后直接前往；保存失败留在暂停页重试。武器搭配、本领一览、选项从「更多」进入。

三稿用内置 ImageGen 参考当前游戏 1280 × 720 的选关、选角、游玩和暂停实机截图生成。图中字号、字形与操作距离供挑选方向；实机手柄和儿童试玩留到选定方案后验证。
