# 打击音效、怪物遭遇与三条生命方案

2026-11-14。用户已明确：做好各武器打击音效，增加小怪数量与形式，让 BOSS 战更频繁；一条命对应一整条血，受击先扣血量，血条耗尽才扣命，默认 3 条命，奖励可以增加命数。本方案已获授权并完成本轮实现；验证范围及尚未实机验证的项目见 README 的“本轮实现与验收”。具体适龄数值仍可按儿童试玩继续调整。

## 命数与血量

统一使用两个清楚的含义：命数是还能使用多少条血条，血量是当前这一条还剩多少血。界面用“血瓶 ×3”和“血量 100/100”分别表达。默认 3 条命包含当前正在使用的一条，另有两条备用；每条血量上限暂定 100，不引入额外体力或法力条。

| 事件 | 当前血量 | 命数 | 结果 |
| --- | --- | --- | --- |
| 新冒险 | 100/100 | 3 | 使用第一条血条 |
| 被小怪打中，示例伤害 10 | 90/100 | 3 | 扣血并短暂保护，继续游玩 |
| 被 BOSS 打中，示例伤害 25 | 65/100 | 3 | 扣血并显示实际伤害 |
| 当前血量归零 | 0/100 | 2 | 这条命已消耗，暂停并弹出“继续／重来” |
| 选择继续 | 100/100 | 2 | 在死亡附近安全位置使用下一条血，短暂无敌 |
| 拿到回血药包，原为 60/100 | 85/100 | 不变 | 只给当前血条回血 |
| 领取“生命血瓶 +1” | 不变 | 原命数 +1 | 增加一条完整备用血条 |
| 最后一条血耗尽 | 0/100 | 0 | 同样弹窗；继续不可用，可选择重来 |

- 命数只在血条耗尽时减一。一次伤害事件最多耗掉一条命，超额伤害不穿透到下一条；下一条血在确认继续时开始使用，恢复动作不会再扣一次命。
- 小怪普通碰撞初步扣 10，强攻击扣 15；BOSS 普通技能扣 20～25，重击初步扣 35 且提前明显预告。它们是待试玩值，按招式区分，不因高叠加武器强行抬高敌方伤害。
- 受击保护初步 1 秒，复活保护初步 3 秒，按有效游玩时间计。一次接触的身体、弹道和残留伤害共享受击保护，避免一瞬间连续扣空；护盾先按既定顺序吸收伤害，同一次攻击只消耗一个护盾来源。
- 掉坑建议扣当前血量的固定伤害，初值 25，并回到最后站稳的安全坑边；只有这次伤害让血量归零时才减命。回坑边给短保护，不借掉坑自动补满血。此提案替代掉坑固定扣一命的旧方式。
- 普通受伤、掉坑或减命不清空已学武器、传奇效果和成长。零命后结束本次冒险；暂停、换关、进休息点和重开界面不会补满血或补命。
- 游戏对外文案固定用“血量”“血量上限”“命数／条命”。“恢复生命”这样无法区分回血和加命的文案改为明确的效果。

## 血条耗尽后的选择弹窗

每次血量归零都立即暂停并弹窗，由玩家选择“继续”或“重来”；包含小怪、BOSS、机关或掉坑造成的血量归零。受伤但还有血时保持正常游玩。

- 弹窗显示“这条血用完了”和已经扣除本次消耗后的剩余命数，仅保留“继续”“重来”两个操作。角色、怪物、BOSS、弹道、充能与限时道具全部暂停，不倒计时、不自动复活。
- **继续**：命数大于零时可用，在死亡附近安全落脚处使用下一条满血血条，掉坑则回到最后站稳的坑边，并给予短暂保护。保留当前地图、敌人和 BOSS 剩余血量、积分、武器、传奇效果、成长与已领取内容；不再次扣命。
- **重来**：方案按“重新开始整次冒险”设计。保存并结束原冒险成绩，保留当前角色及这次出发时的初始自选搭配，从第一小关生成新的随机冒险，恢复默认 3 条命与初始血量上限，重置本次探索获得的武器、传奇、成长、资源、限时效果和领取状态。历史成绩、花园成就、贴纸与其他小游戏存档保留。
- 弹窗中用一句话说明“重来会从第一小关出发，重置本次成长”。最后一条血耗尽也显示该弹窗，写明“命数用完了”，禁用继续并说明原因；只有重来可以启动游戏，不能借继续获得无限生命。
- 弹出时清空并拦截仍按住的移动、攻击、跳跃输入，初始不默认选中操作；等待旧按键松开后才能通过新的明确操作选择。重复点击、键盘与鼠标交替触发共用防重，关闭弹窗或按 Escape 不能绕过选择恢复游戏。
- 扣命完成、待选择状态和安全复活位置一起保存。刷新或退出后恢复该弹窗，不能再次扣命或自动选择；继续与重来分别只提交一次，重来使用新冒险身份，原成绩不重复结算。

## 补给与成长

| 内容 | 新含义 | 限制与显示 |
| --- | --- | --- |
| 蓝瓶爱心／生命血瓶 | 命数 +1，增加一条备用血条 | 使用血瓶图案及“+1 条命”；当前满血也能获得，不顺便补满当前血 |
| 回血药包 | 恢复当前血量，初值 25 | 独立药包素材及“回血 +25”；满血时按已有暂放／备用规则处理 |
| 血量上限成长 | 所有血条的最大血量增加，初值 +20，同时当前血量 +20 | 命数不变；既有备用血条在使用时按最新上限恢复 |
| 花瓣护心 | 击败规定数量的合格小怪后恢复当前血量 | 初步每 12 只回 10，不增加命数，召唤子怪不刷恢复计数 |
| 备用点心／备用补给 | 保存一次回血药包，非致命受伤后自动回血 | 不自动增加命数，也不在零命后复活 |
| 星云甘霖 | 每次恢复当前血量的固定量，初值 10 | 每次施放最多回复一次，攻击成长不放大回血，不增加命数 |
| 小小勇气等低血保护 | 根据当前血量触发，初步阈值为 20% | 不能继续用“只剩 1 命”代替低血判定；明确保留每关触发次数 |

成长材料原来的生命上限增长迁移为血量上限增长，攻击成长继续保留。增加命数使用单独的生命血瓶奖励，避免孩子收集普通计分爱心时不清楚加了什么。

白、蓝、紫（史诗）、传奇的品质体系和每小关至少一个有效传奇选项继续保留。加命奖励可以随品质增加收益，初步建议：蓝色生命血瓶 +1 命；史诗生命补给 +1 命并回复当前血量；传奇“守护血瓶”+1 命，并使下一次因血条耗尽而复活后触发一次清除附近普通敌弹的保护波。保护波只消耗已领取的一次机会，不反复刷，不能清除 BOSS 机关或预告。具体恢复量与传奇额外效果待确认。

## 五类主武器的打击音效

声音需分别表达发射、飞行／持续、真实命中、格挡和击败。以轻快、清楚、有弹性的童话音色为主；所有素材本地打包，离线播放，Mac 与 Windows 使用同一音频。准备可循环片段和短促单次片段，采用有明确授权的素材或原创制作。

| 武器 | 发射与持续声 | 命中声 | 击败反馈 |
| --- | --- | --- | --- |
| 彩虹星雨 | 轻巧的木琴／星铃短音，连发节奏清楚 | 短促“叮啪”，命中多目标时有轻微音高变化 | 一小段上扬星铃 |
| 魔法泡泡 | 柔软的水泡“啵”，飞行时保持安静 | 有低频弹性的“噗啪”，爆圈多目标仍为一次主要爆破声 | 泡泡散开的短水滴音 |
| 圆月弯刀 | 快速、轻薄的破风声；密集连发时合并同批声音 | 清脆短切声加柔和铃音，不用写实刀砍声 | 一声干净的月牙亮音 |
| 彩笔火龙 | 很短的点火声，接柔软喷气循环；松开攻击平滑收尾 | 低音量的细碎噼啪，按命中节奏采样播放 | 火星散开的轻“噗”声 |
| 贯穿光刃 | 有方向感的短“咻”，比弯刀更厚实、节奏更慢 | 明亮且短促的穿透声，沿途目标命中分组反馈 | 简短的光亮和弦 |

既有扩展武器也要有独立音色：回旋星镖去程、回程使用方向不同的双段破风；花种弹用轻抛与开花的木质弹响；萤火法杖用细小的闪光音。四种大招分别用火环的温暖呼声、风雪的沙沙声、雷链的弹性电响、甘霖的水滴与雨声，每种包含起手、持续和结束层次。

- 命中音只在实际命中后播放，护盾格挡使用更闷的短响；BOSS 破盾、玩家受伤和损失一条命各有独立提示，孩子能听出发生了什么。
- 同批多发合并发射音，50～80 毫秒内同类命中合并；持续火焰的命中音初步限每秒 5～8 次。至少准备三种轻微变体，避免长时间同一声音重复刺耳。
- 同屏声音并发初步限制 12 个，优先保留 BOSS 预警、玩家受伤、破盾和大招；普通射击适度压低。音量不随 20 把弯刀变成 20 倍，也不能把成长后的声音全部静音。
- BOSS 预告与玩家受伤提示始终清楚；大招和击败声音不能遮住预警。不用尖锐爆炸、长时间震动或吓人的惨叫。
- 暂停、领奖、退出立即淡出循环声，恢复时按当前状态续播，不重放旧命中。营地与实战共用同套音效，支持已有静音操作。
- 试玩要同时检查命中动画、实际扣血数字与声音的时机，覆盖单武器、多武器、密集怪群和 BOSS 战，不能仅以能播放音频作为验收。

## 更多小怪与遭遇形式

现有 24 种怪物保留，建议先增加到至少 30 种，每个世界增加有主题关联的候选。增加数量的起始调参目标为相同小关、同种子可遇独立敌人比当前多约 50%，同时增加混合行为与分批进场；最终按实际路线容量与儿童试玩调整。

| 新怪物提案 | 行为差异 | 应对方式 |
| --- | --- | --- |
| 纸飞机怪 | 按有预告的弧线掠过，回转时短暂停顿 | 在掠过间隙跳跃，或用月牙追击 |
| 气球团 | 在上下平台间周期升降，短暂占据一条通路 | 看升降节奏，从另一高度通过 |
| 墨水章鱼 | 抛射墨滴，落地形成短暂减速区 | 离开落点标记，攻击它抛投后的空档 |
| 冰壳企鹅 | 外壳先挡一次攻击，破壳后短距离滑行并停顿 | 先破壳，再抓停顿；破壳声清楚 |
| 积木双子 | 两只轮换护卫和射击，护卫有明显空档 | 换站位或等交接空档，各只仍可被基础武器击败 |
| 蒲公英怪 | 吹风改变附近小怪的行进路线，吹完停下 | 优先处理它，减少包抄；风不把玩家直接吹下坑 |

地图组合至少覆盖地面小队、空地夹击、高台抛射、两侧轮流进场、护卫与远程组合、有限召唤、移动平台追逐和中段首领护卫。每个战斗房间以 2～3 种行为搭配，主题与路线决定候选，连续房间避免重复同一种组合。

前期同时主动进攻先控制在 3～4 只，后期 5～6 只；其余分波进入视野或保持待机。每波结束安排短暂收集与移动空隙；远程攻击必须来自玩家可见区域。入口、复活点、必要落脚面保留安全空间，召唤与分裂计入同屏预算，刷出的子怪不反复提供奖励或补给保底。

新局随机组合与进场顺序；当前局的怪物身份、已击败状态、剩余波次、掉落与已领取状态保存。提高遭遇量不改变旧档本关布局，已有局从下一小关接入新版。

## 更频繁的 BOSS 战

建议每个小关安排一次中段小 BOSS 与一次终点 BOSS，每个世界第三小关再接大关 BOSS。24 小关共 24 场中段战、24 场终点战、8 场大关战，至少 56 场；较长小关可以额外安排一次中段战。

- 主路以 2～3 组普通遭遇后遇到中段 BOSS 为起点；按正常推进约 45～90 秒一次首领遭遇作试玩节奏目标，不用计时器刷首领，也不因探索支路而强行拉入战斗。
- 中段小 BOSS 主打一个清楚招式和一个变化，例如追逐后停顿、召唤护卫后暴露弱点、升降平台上的抛射。建议战斗约 15～25 秒；较低血量，单把基础武器也有明显输出。
- 终点 BOSS 组合两项主题技能，建议约 25～40 秒；大关 BOSS 有两阶段，建议约 40～60 秒。以上均为目标，需以四角色与五基础武器试玩校准，不通过无敌等待延长时间。
- 中段、终点和大关 BOSS 需要不同的技能组合、移动模式与场地互动。高低平台、追逐走廊、开阔教学、机关破盾按世界搭配；同一主题的首领也不能只放大体型或增加血量。
- 所有首领都主动移动，技能能威胁地面与高台，但保留充分预告和反击空档。护卫数量计入同屏预算，首领的关键预告出现时不叠放其他高威胁招式。
- 中段 BOSS 击败后记分并可掉一个固定回血药包，靠近拾取，无新武器选择弹窗；掉落与领取防重。通关才集中弹出原有选择面板，仍保证至少一个有效传奇选项；第三小关连续两场后统一结算。
- 每个首领及其护卫记录独立状态；暂停、复活、重进不重刷已击败首领、不补满它的血，也不重复计分。

## 旧档迁移与验收

目前单条生命实现把 `lives/maxLives` 同时用于当前血量和上限，不能直接把旧值解释成新命数。开发时需为命数、当前血量、血量上限分别存储并更新版本：

- 未结束的单血条旧档保留原血量比例和已获上限成长，再配置新规则的 3 条起始命；旧值 9 不等于 9 条命。已结束冒险保持结束，不通过迁移复活。
- 更早的真正“命数＋血量”旧档保留其剩余命数，并按比例迁移当前血量；不得统一覆盖为 3。历史积分不改写。
- 首次迁移先备份；迁移版本、已扣命的死亡状态、待复活地点及剩余保护时间一同保存。读档不重复加命、扣命或补满血，已有武器、传奇、奖励与地图进度完整保留。
- 全部恢复、补给、成长材料、低血技能、大招回血、休息点与状态文案都按新语义调整；不能只把 HUD 改成两项，而底层继续扣命。
- 验收至少覆盖受击扣血不减命、每次归零弹出继续／重来、归零仅扣一次命、继续保持地图和构筑、重来重置范围、零命禁用继续、持续按键防误触、重复点击防重、待选择状态读档，以及三命计数含当前命、加命不回血、回血不加命、血量上限成长、掉坑与复活、暂停与旧档迁移。音效在真实攻击中验收，遭遇与首领节奏在新旧存档分别验证。
