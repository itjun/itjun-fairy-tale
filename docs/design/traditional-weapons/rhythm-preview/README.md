# 第 2 组动态打击预览

2026-11-17。用户已选“连段节奏”，仅授权先做动态预览，并要求每一种武器有不同声音。**本目录未接入游戏；继续等待用户确认动作与音效后再开发。**

## 入口

`index.html` 是可离线打开的独立 HTML，内嵌人物、兵器、风火轮、练习靶、字体、已选图片和八份音频。页面不读取或修改游戏存档，不持久化预览状态。

- 选武器后点“打一次”，或用空格；“连续演示”可重复观察。
- 支持 0.35 倍慢放、暂停与继续、拖动定格、范围显示。
- 把靶子移远、抬高，或切到空中，比较命中与挥空。挥空不播放击破声。
- 四个独立试听按钮播放各兵器完整一轮；切换、暂停或离开页面立即停止旧声音。慢放不改变声音的音高。

## 已选动作和声音

| 武器 | 动作 | 命中时刻（秒） | 基础伤害 | 完整周期 | 声音 |
| --- | --- | --- | --- | --- | --- |
| 唐刀 | 从低到高上挑，宽直竖向亮痕 | 0.120 | 72 | 0.50 秒 | 干脆单响，保留底样原始音高、缩短尾音 |
| 火尖枪 | 火焰绕枪尖螺旋前钻，脚下双轮 | 0.160、0.270 | 48＋48 | 0.70 秒 | 更亮的火焰抖尾，两次分别发声 |
| 青锋剑 | 上中下三点连刺，短线与菱形落点 | 0.065、0.125、0.185 | 14＋14＋14 | 0.30 秒 | 音高更高、尾音更短的清脆三连响 |
| 方天戟 | 举起后下砸，贴地三角碎光向两侧扩散 | 0.280 | 126 | 0.90 秒 | 低沉重击与较厚余音 |

范围沿用第 2 组数值提案。空中戟只判定戟尖附近，没有地面冲击；靶子太远或太高时不会因播放动画而自动受到伤害。预览中的单只练习靶每轮重置，展示每段命中、闪光、伤害与打倒反馈；并未实现真实游戏中的敌人 AI、护盾、多人群伤或奖励。

每次命中让动作姿态短停约 35 毫秒；计时继续前进，整轮周期不额外延长。每轮结束后额外留 0.48 秒审阅停顿，“连续演示”不等于游戏连发速度。风火轮只随火尖枪出现，不附加位移或无敌。

## 画面实现

以 `../moveset-options/rhythm.png` 为动作来源，保留女儿原画人物与已定兵器 PNG，不替换为通用卡通人物。底色 `#fbf8f0`、纸面 `#fffdf7`、墨线 `#292b32`；刀蓝、枪橙、剑绿、戟紫用于标识招式。沿用本地霞鹜文楷。顶部选四件兵器，中间为大幅动态画面，下方是播放与音效审阅。

这是动作示意：人物使用现有攻击姿态配合位移、残影和持械旋转，尚未制作逐帧手臂骨骼动画。刀光、螺旋、刺点和震波由 Canvas 按时间绘制；不把选中的四格概念图直接当作实机画面。实现后已调整持械层级，避免戟杆遮住人物脸部，并把连续伤害数字分开。

## 音效来源与制作

底样是先前已验证的 `../audio/ng3-enemy-break.wav`；来源记录在 `../audio/source.json`。四件兵器分别生成独立 WAV，以重采样、滤波、包络和短尾节奏改变声音。没有重新采用此前被否决的振荡器／随机噪声替代方案。

这四个声音是**基于 FC 原版击破声的衍生设计**，不是四条未经处理的原游戏音效，也不宣称已得到用户听感确认。

- `audio/*-impact.wav`：每段命中使用的四种独立音效。
- `audio/*-phrase.wav`：完整一轮试听，时序与动作表一致。
- `audio/four-weapons-comparison.wav`：按唐刀、火尖枪、青锋剑、方天戟顺序对比，间隔半秒。
- `audio/design.json`：处理参数、时长、峰值、RMS 与 SHA-256。
- `build-audio.py`：仅处理现有底样，生成独立衍生文件，保留原样本。

## 本地生成

```sh
python3 docs/design/traditional-weapons/rhythm-preview/build-audio.py
node docs/design/traditional-weapons/rhythm-preview/build.mjs
```

现有本地设计服务在 4399 端口，可访问 `/traditional-weapons/rhythm-preview/`。没有新增项目依赖、安装桌面包或发布。

## 验证范围

- 语法检查与本地 HTTP 200 通过。
- Codex 内置浏览器实际点击四件兵器，命中次数依次为 1、2、3、1，伤害为 72、96、42、126；声音事件分别使用各兵器独立音效。
- 方天戟在空中定格时无地面震波，地面目标未被命中；移远后整轮伤害为 0。
- 慢放暂停后时间保持 0.085 秒不前进；继续后只触发剩余两段，总计 3 次、42 伤害。连续演示跨轮重置命中数，停止与拖动定格可立即中断。
- 四个独立试听按钮均走完浏览器播放流程并显示试听完成；浏览器控制台无错误。这里只验证音频解码、播放与时序，听感由用户确认。
- 四份命中音效散列各不相同；单次及整轮样本峰值均低于 -1 dBFS，无 PCM 满幅削波。
- 画面与数值仅在此独立预览验证，不代替游戏中的碰撞、敌人行为、成长和平衡测试。音色是否合意仍由用户试听确认。
