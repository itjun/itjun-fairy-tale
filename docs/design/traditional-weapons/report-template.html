四种兵器，四种轮廓

点击兵器查看造型依据与动作设计。钢灰刃口、细长杆身、铜色和红绸；火尖枪增加橙金火焰与脚下双轮。素材以实际轮廓辨认武器种类。

选中火尖枪，脚下出现风火轮

四位角色都能用。双轮在脚下缓转，出招时加快并带出短火尾；切换下方的试用角色，风火轮也会跟随。

暂按随身外观设计：站立 1.2 秒一圈，动作时 0.6 秒一圈，火尾约 0.25 秒淡去；伤害与移动规则沿用原提案。

基础数值提案

近战需要接近敌人，基础理想输出设计在约 137～144 伤害/秒。四种兵器的单体理想输出接近，主要用距离、起手、范围和命中人数区分，而不让大武器全面胜出。

武器每击伤害完整一轮最大距离单次最多命中理想输出 / 秒

基础条件：武器 1 级、无成长、无攻速、无传奇；伤害/秒＝单次伤害 ÷ 完整一轮。真实战斗还包含接近、挥空、格挡、首领承伤限制，不能把这个数当作实测。火尖枪的风火轮暂按外观特效设计，不额外计入伤害或移动加成。

动作怎样分配时间

武器起手有效攻击收招动作重点

按住 X / RT 或 J 连续攻击；每轮收招后才开启下一轮。地面和空中都能用，移动、跳跃不锁死，也不增加新按键。

调一调成长后的数值

近战连击数量上限是新增提案，当前游戏尚无此规则。该上限只限制一次动作的重复次数；超过 3 级后，重复奖励仍提升伤害。此计算器不叠加角色天赋、套装、传奇追加与连锁伤害。

为什么要限制连击数量

建议同武器每轮最多 3 连击，“双重发射”可提高到 4 连击。增加连击也会延长本轮动作，避免几十把近战同时挥舞遮住角色；刀、枪、剑、戟可以与已有远程武器共同装备。

品质与传奇

沿用普通、稀有、史诗、传奇四档。品质不再额外乘一个伤害系数：重复获得按等级成长，传奇增加各自招式。以下四个传奇效果也需要你确认。

首领与轮回边界

确认后验证单把基础近战的目标体验：首领能看清预告、至少完成几轮出招，交战时长向约 14～20 秒校准。这是设计目标，尚未用这四种武器跑过战斗。

沿用每 1.5 秒最多扣除首领最大生命 12% 的限制，以及八世界一轮的既有规则。近战的额外连斩、传奇和角色天赋都计入同一个首领承伤上限；不会因武器多而绕过。

攻击与命中

刀、戟沿面前扇形挥砍，枪直刺，剑小幅快击。每一记对同一敌人只结算一次；护盾挡住后，这记不再继续造成伤害。刀、戟的多人命中是近战提案，不改变远程“遇敌消失”的规则。

成长与天赋

重复武器增加伤害和连击；攻速缩短完整动作。妈妈与姐姐按“发起一轮”累积天赋次数，追加连击和传奇动作不再次计轮；爸爸护盾、妹妹二段跳保留。

效果搭配

冰霜、连锁、分裂仍可作用于有效命中。分裂奖励产生星弹，基础刀枪剑戟自身不发射远程剑气。范围本领每级增加 10% 距离，上限 3 级；不增加可命中人数。

获得方式

四种近战都可在营地自选为唯一开局武器，也进入现有武器奖励池。初始不附送额外武器，原四人的远程推荐搭配先保留。角色下方的近战搭配只是试用建议，不锁定角色。

保存与暂停

需保存本轮动作进度、已经命中的目标、剩余连击和收招时间。暂停冻结，读档接着挥；不能借暂停、离开或恢复多打一次。地图仍用第 11 版。

儿童操作

攻击可在移动和跳跃中使用，不自动冲刺、不把人物拉向敌人。火尖枪需要调整高度，风火轮跟随移动和跳跃，不提供悬空飞行；戟保留明显起手，挥空也要收招。战斗保持彩笔效果，不增加血腥表现。

确认后的验收项目

  • 四位角色站立、移动、跳跃与攻击时颜色一致，握柄不漂移，武器大小不遮住角色。选用火尖枪时脚下显示一对风火轮，移动和跳跃跟随，暂停冻结，换下后移除；重复获得不叠加轮子数量。
  • 四种近战在左右面向、空中、平台边缘、护盾和多个目标下，实际命中与可见动作一致。
  • 营地选择、键鼠、Xbox 模拟输入、奖励、暂停与存档接续采用同一套规则。
  • 单近战、近战连击、近远程混合构筑分别挑战八位首领；记录出招次数与实际用时，再校准数值。
  • 单独报告实体 Xbox、Windows 与儿童试玩结果，不把模拟输入或数学计算当作真实试玩。
