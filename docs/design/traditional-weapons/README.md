## 火尖枪与风火轮提案

枪类按最新反馈改为火尖枪，朱红长杆配橙金火焰枪头。选择或装备火尖枪后，脚下立即显示一对风火轮；四位角色通用，换下火尖枪后移除，重复获得仍只显示一对。风火轮跟随脚部移动和跳跃，暂停时冻结，恢复时随装备还原。

- 单轮直径约为角色身高的 30%；站立时约 1.2 秒转一圈，移动和出招时约 0.6 秒一圈。
- 火尾最长约 0.45 个角色身高，约 0.25 秒淡去，保持角色与平台落脚点清楚。
- 当前按外观特效提案，不额外增加伤害、移速、跳跃高度、飞行或无敌。基础伤害仍为 96，完整一轮 0.70 秒，距离 1.55 个姐姐身高，基础命中 1 名目标。
- HTML 中选择火尖枪即可看到双轮持续转动，点击“演示一次”可看直刺与加速火尾；更换试用角色仍保留效果，切换其他武器移除。减少动态效果时显示静态双轮。报告仅为设计示意，尚未接入游戏。

## 成长提案

- 单击伤害沿用现有成长公式：`round(基础伤害 × (1 + 攻击成长 × 10% + (武器等级 − 1) × 20%))`。武器等级上限仍为 99，攻击成长上限仍为 100。
- 普通近战连击数建议为 `min(等级, 3)`；拥有双重发射时翻倍，最终上限为 4。这是新增待确认规则，避免同一轮几十次挥舞遮挡画面；超过三级仍增加伤害。
- 每增加一击，刀/枪/剑/戟分别增加 0.24/0.32/0.16/0.40 秒的本轮占用时间。
- 本轮时间为 `(基础周期 + (连击数 − 1) × 追加间距) / (1 + 攻速等级 × 18%)`。整轮结束才能再开一轮，攻速同时缩短起手、攻击与收招。
- 范围本领每级增加 10% 距离，最多 3 级，不增加单击命中人数。计算器专注等级、攻击成长、攻速与双发，不计范围、天赋、套装、传奇或连锁的额外伤害。
- 四种近战与现有远程可叠加装备；同种武器各自排队。不增加按键，仍是 X/RT 或 J，地面和空中均能攻击。

## 品质与传奇提案

沿用普通、稀有、史诗、传奇四档，不直接由品质乘伤害系数。重复获得按等级成长，传奇增加专属效果：

- 唐刀「回风斩」：每三轮追加后向半伤横斩，本轮多 0.15 秒。
- 火尖枪「破阵枪」：第一名敌人未格挡时，可再刺中一名，第二名受 50% 伤害；护盾截住直刺。
- 青锋剑「连环快剑」：每四轮追加 60% 伤害前刺，本轮多 0.10 秒。
- 方天戟「开山戟」：对护甲、硬壳、精英有效伤害加 20%，对首领加 10%，不绕过格挡与首领承伤上限。

附加动作不再触发“每四轮”等轮次被动，避免递归。妈妈、姐姐按发起一轮累计天赋，爸爸护盾和妹妹高二段跳继续保留。
