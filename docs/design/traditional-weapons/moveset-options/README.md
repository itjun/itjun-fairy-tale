## 数值

刀、枪、剑、戟沿用 72 / 96 / 42 / 126 的基础伤害预算，以及 0.50 / 0.70 / 0.30 / 0.90 秒的完整周期。连段在预算内拆分，必须各段实际命中才结算；多段覆盖不同方向时，不能直接把所有段数当成必定命中的单体输出。基础目标数上限为 3 / 1 / 1 / 4。

这些是供选择的提案，不是游戏实测。选择后再整合逐帧动作、成长与传奇效果，特别要避免回身双斩与旧唐刀传奇产生重复设计。沿用家人、简单攻击键、近战与远程可叠加等既定方向；新动作尚未接入引擎。
