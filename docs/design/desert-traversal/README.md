# 沙漠地图、攀岩与洞窟设计稿

## 高崖与独立洞窟修订

砂岩大峡谷从谷底到崖顶约 18.5 单位高。沿岩面攀到第一层后，站稳，再跳抓错开的上一层。三段岩壁各有落脚台，镜头随角色往上看，爬到崖顶才能走到峡谷另一边。[高崖修订图](high-canyon.png)

砂岩峰从山脚到顶约 26.4 单位高。三段岩面各有一条紧凑的凸石路线，中途要贴着岩棱横移换手，然后翻上歇脚台，再跳抓下一段。岩面以天然色的凸石和粉笔短划表示抓点。方向键或摇杆选下一处，贴墙连续爬升用向上，跨空档按跳。

站在抓点附近的台边按下可以重新抓住岩壁。砂岩峰按住向下会沿抓点退回歇脚台，连续岩壁则向下移动。停下方向输入会继续抓稳。半途松手用方向向下加跳。

松手下坠时，朝岩壁移动或向上推，可抓住下方够得到的岩面或凸石。抓稳后可以继续攀爬。

沙漠灯笼洞口切换到独立地下区域。种子决定进入晶潭洞窟或风蚀石窟。晶潭进门后下降再爬出，风蚀石窟逐级上升。两种地图都有八块主要石台、上层寻宝支路和可以往返的出口。洞内镜头、落脚点和宝物都跟随这张地图。[独立洞窟修订图](independent-cave.png)

第 11 版存档继续可用。高崖平台、新洞的落脚点和宝物从编号尾部追加。停在旧短洞里的存档可以走原来的两个出口，下次从地表进洞会进入新的洞窟地图。

## 沙漠路线

沙漠绿洲是第九个世界，四间房加一场首领，过关后进入下一轮。每局都会经过三种地形和一面攀岩墙。选门仍影响关卡事件和奖励，随机种子改变局部路线和抓点布置。

| 房间顺序 | 怎么玩 |
| --- | --- |
| 1 · [砂岩峡谷](sandstone-canyon.png) | 从矮墙练习贴墙，再蹬到对面的岩壁。下面有平地，跳空就落回练习处。 |
| 2 · 攀岩墙 | 在同一片岩面上换抓点。主路经过宽歇脚台，可选支路需要横移和跨点跳，能摸到一颗星星。两路在顶部汇合。 |
| 3 · [风车遗迹](windmill-ruins.png) | 跳抓矮墙、石柱和木梁，逐次向上到风车台。下方的缓坡能回到最近的站台。 |
| 4 · [绿洲洞窟](oasis-caves.png) | 从灯笼下钻进短入口，穿过宽洞室，再从另一头爬回绿洲。洞室内有可选寻宝岔路。 |
| 首领场 | 两侧各留一段短攀岩路线，并接宽站台，方便换层躲招。 |

图中的跳距示意供确认玩法。搭地图时把风车遗迹第一处抓点放在迎着玩家的一侧，从石柱跳往横梁要能越过柱顶。绿洲钻过第一段短洞口后分路，地表短路和洞内寻宝支路都能回到同一歇脚台。

## 攀岩玩法

- **抓到第一点。** 从安全地面朝岩面的凸石跳，进入够得着的距离就自动抓稳。墙面仍保留蓝绿色双短线，攀岩的离散抓点用凸出的蓝绿石块表示。
- **选方向换手。** 左摇杆推向可达抓点，角色伸手换到该点，再收脚。轻推一次走一格，回中后可以停下来挑路。可达抓点在边缘亮一圈，其他抓点保留原色。玩家可向上、横移或往下退。
- **跳过远处空档。** 抓稳后朝目标按 A，蹬墙跳出，靠近下一块抓点自动接住。若想返回地面，向下＋A 松手。触屏有四向控制和原跳键，键盘用方向键或 WASD 和空格。
- **累了就上平台。** 基础攀岩无体力条和抓握倒计时，路线中途有宽歇脚台。轻松路线只需换抓点即可登顶，跨点跳首次出现在有安全落脚面的支路。暂停保持当前抓点，退出后续关回到同一小段最近站稳的位置。

攀岩用同一片有抓点的岩面，短墙攀爬则在墙边连续上移，风车遗迹主要在不同障碍之间跳抓。开场只教短墙。第二间房先给一小段顺着抓点就能走通的岩面，再出现横移和分支。首轮练习区留出无怪空间，熟悉后再把小怪放在站得稳的平台附近。

## 按键和反馈

| 动作 | Xbox | 键盘 | 画面提示 |
| --- | --- | --- | --- |
| 抓墙、攀爬 | 朝标记面跳，碰到就抓住，左摇杆向上爬 | 朝标记面按方向＋空格，抓稳后按 W 或 ↑ | 可抓的一侧画蓝绿色双短线，抓住时收脚贴墙，短线亮一下。到顶后自动翻上安全站台。 |
| 从墙上或障碍起跳 | 抓住后松开再按 A，摇杆可选跳向 | 松开再按空格，方向键可选跳向 | 第一次显示下一处抓点。墙上起跳自然蹬离墙面，障碍侧抓起跳主要向上。 |
| 下攀与松手 | 左摇杆向下爬，同时按 A 松手 | S 或 ↓ 往下爬，再按空格松手 | 台边提示可以抓回岩壁，悬挂时提示松手操作。 |
| 钻进洞窟 | 站到洞口旁，摇杆往上推进入 | 在洞口按 W 或 ↑ | 灯笼和低矮拱口提示入口，接近出现“进洞”。角色自动低头通过短入口，进宽洞后恢复普通移动与跳跃。 |

触屏沿用方向、跳跃和情境“进”按钮，抓住墙时提供向上爬的触屏操作。四位家人都能过基础路，妹妹的二段跳仍跳得更高。悬抓期间可攀爬、起跳或松手，回到普通移动后恢复攻击。墙顶和障碍侧面用同一套颜色与形状标记。

洞口用原玩法的情境键主动进入，与房间尽头会发光的门各用自己的提示。洞内用浅紫、蓝灰和灯笼保留纸面亮度，镜头跟进洞内，让入口、脚下和下一落点可见。探索洞是房间内的分支，从另一头回到本房间，保留退回入口的路径。洞内的星星或碎片直接拾取。必清怪放在经过主路就能到的战区，洞里的可选目标不拦门。

## 放进现有八个世界

| 世界 | 可以抓的地方 | 洞窟与低路 |
| --- | --- | --- |
| 彩虹花园 | 矮土墙 → 稳定云台 | 花根底下的浅洞，回到弹簧旁 |
| 家人小镇 | 屋侧砖墙 → 雨棚边 → 屋顶 | 矮拱门穿过小屋底层，从钟摆另一侧出来 |
| 甜甜城堡 | 饼干柱 → 糖砖墙 | 开桥后露出糖洞，沿下路回到传送带旁 |
| 贝壳海边 | 抓码头侧面或贝壳崖 | 从干燥的潮洞绕过岩壁，在木筏另一端出洞 |
| 风车草地 | 从跷跷板跳抓风车梁 | 穿过草丘下的兔洞，在另一侧升降台旁出洞 |
| 雪人乐园 | 抓积雪露出的粗岩或木桩，光冰面仍滑 | 冰窟内沿缓坡走，从岩边爬出 |
| 蘑菇森林 | 树皮抓墙 → 树枝接力 | 从树根洞钻进去，沿树干另一侧爬回树屋 |
| 卡通梦工场 | 传送带送到积木堆旁，跳抓积木侧面 | 从维修洞穿到另一侧，在火箭台前汇合 |

家人小镇的砖墙、贝壳海边的岩壁和蘑菇森林的树干都可放一小段攀岩路线。抓点分别画成凸砖、贝壳岩块和树结，沿用蓝绿色标记和可达高亮。

## 随机地图与续关

用成组的墙面、抓点、落脚台和成对洞口生成路线。房间内暂停、续关都回到原来的洞内或地表进度，宝物领取状态随同局保存。停在墙上时，续关回到同一小段最后站稳的安全位置。继续使用第 11 版存档。旧八个世界保留原房间、平台、宝物与敌人编号，新支路的平台和宝物追加在尾部。

验收时用四位角色走通第一次抓墙、完整攀岩主路、横移取星支路、两次障碍接力跳、洞内两条路和续关。检查摇杆回中时能原地悬抓、够不到的点不会直接吸过去、持续按跳不会反复蹬墙。抓点间距、攀爬速度和自动抓取范围在试玩后定。
