# 初始技能搭配与小怪生命补给

用户于 2026-11-13 要求：选角色时支持自动搭配，也允许玩家自选初始技能；玩家与 BOSS 都显示血条，小怪偶尔掉落可以主动选择的生命道具。视觉依据为用户提供的现有角色营地截图 `camp-reference.png`，沿用原人物、彩笔营地和纸面按钮。

## 初始搭配

每位角色选择 1 种武器、最多 2 项本领；原有角色天赋另行保留。可选现有全部 7 种武器及基础本领，增加发射数量、分裂、追加攻击的本领留到探索奖励中获得；武器专属本领要求先装备对应武器。切换武器时会移除已不适用的专属本领。

| 角色 | 自动推荐武器 | 自动推荐本领 |
| --- | --- | --- |
| 爸爸 | 圆月弯刀 | 叶片护甲、花瓣护心 |
| 妈妈 | 圆月弯刀 | 冰霜、花瓣护心 |
| 姐姐 | 圆月弯刀 | 轻快连发、宝物磁吸 |
| 妹妹 | 圆月弯刀 | 轻羽缓落、安稳落脚 |

四位角色默认只有一把圆月弯刀，各武器基础只发射一枚。探索奖励可以获得新武器或叠加同种武器的数量和伤害，见 `../moonblade/README.md`。

“自动搭配”恢复该角色推荐。“自己选择”编辑草稿，确认后更新营地试用与正式出发的构筑；返回则保留之前的组合。营地展示所选武器的真实发射、冷却和攻击强化；资源恢复、受伤等被动效果在正式关卡中触发。旧冒险与跨关继续沿用已有构筑，不重置为推荐，也不会把主动未选的圆月弯刀重新装备。

## 单一生命条

玩家初始生命为 9/9。受伤扣当前生命，补血只恢复当前生命，生命成长提高上限并增加条宽；不恢复体力，也不另加独立的复活命数。玩家和 BOSS 均展示当前/最大生命，零生命结束冒险。此前的 BOSS 命中数字、成长材料与跨关成长继续保留。

## 小怪掉落

- 每小关最多掉落 3 份补给，BOSS、分裂子怪和召唤怪不产生此类掉落。
- 每次掉落后至少击败 3 只合格小怪才可能再掉；第 3～7 只每只概率为 24%，第 8 只保底。使用地图种子和怪物编号计算，同局恢复不重抽。
- 补给放在附近稳定平台，角色靠近后自动暂停并弹出三选一，不再显示额外的“选择补给”按钮。弹出时清空持续移动、跳跃和攻击输入，初始不选卡，不自动领取。
- 爱心补血：立即恢复 2 点。生命长大：最大生命 +1，同时恢复 1 点。备用补给：存一份，下次实际受伤后恢复 2 点，不能救活零生命。
- 满血不能浪费补血，已有备用不能重复存；上限达到 99 时不能继续选择生命长大。
- 初始不选卡，必须点选并确认。可以“先放这里”或“保存回花园”。“先放这里”后原地不重弹，离开补给范围再回来才重新弹出。未领取、已领取、待选择和暂放状态均持久化，重复确认不能重复领取。
- 途中仍不频繁发放武器/技能奖励，原小关通关三选一、大关四选二继续保留。
