# X、Y、B 武器搭配

2026-11-20 已确认并接入游戏。玩家在探险中收集武器与主动大招，自由绑定到 Xbox 手柄的 X、Y、B。不同武器可以同时出手（2026-11-24 更新），首领战中也能暂停换装。

## 暂停菜单里的武器搭配

[查看武器搭配页设计稿](pause-weapon-wheel.jpg)

1. 按手柄 **Menu** 或键盘 **Esc** 打开暂停画册，直接选右页的「武器搭配」。
2. **左摇杆指向武器**。对应扇区整块着色，圆心显示名字。松开摇杆后保留这次指向，方便再按目标键。
3. **按 X、Y 或 B**。马上把武器装到该键，底部同步显示新的搭配。游戏继续暂停，可以在同一页调整其他键。
4. 按 **Menu** 或 **Esc**，也可以点击右上「返回暂停」，回到画册。选「继续玩」恢复游玩。

底部三个键显示当前搭配。比如指向「泡泡」再按 Y，Y 就从「弯刀」换成「泡泡」。刚打开时等待玩家主动指向一件武器。圆环只显示已有攻法，每页最多八件，只有超过八件时才显示 RB 翻页提示。

## 战斗规则

- X、Y、B 每格可以装任何已获得的一把近战、远程武器或一个主动大招。在战斗 HUD 里，每格显示按键、武器图标和短名，大招显示能量。A 继续跳跃。键盘建议 J、K、L 对应三格，触屏显示三个独立攻击键。
- 例子是 X 光刀、Y 圆月弯刀、B 雪花风暴。贴近时用光刀，拉开后用弯刀追敌，雪花充满后可以按 B 打一片。也可以把光刀移到 B，或装三把不同的远程武器。
- 不同武器可以同按或交替按。比如 K 发出的弯刀还在飞，按 J 可以立刻发光刃。按住几把武器，各自等本轮弹道、挥斩及派生效果结束并走完自己的间隔后再发。快速点按同一把也遵守这个间隔。
- 多发、分裂、爆炸和传奇效果归入触发的同一轮攻击。大招充满后由玩家按绑定键施放。姐姐第四轮武器攻击附上星光并提高 25% 伤害。同行萤火每隔 `3 / 等级` 秒强化下一轮的首发，增加 `10 + 4 × 等级` 伤害。两种加成随当前武器结算，落地、踩怪和受击反制仍由对应动作触发。
- 主动大招在武器收招后按绑定键施放，施法与回气期间仍占用出手机会。换键和续关时，弹道与冷却跟随原武器。

## 获取与途中调整

- 新局从角色选中的一件武器出发，默认绑在 X，Y、B 显示「空位」。新攻法领取后进本局武器库，玩家自己决定何时装上。再次拿到同一武器仍然提升原武器。被动本领继续随本局生效。
- 可以在正常游玩时暂停换装，包括首领蓄力时。角色、敌人、弹道和计时在整个暂停流程里冻结。被换下的武器回到武器库，选择已绑在别处的武器则交换两格。如果目标格原来是空位，对调后原位置为空。
- B 在日常菜单里继续返回，在搭配页用来装到 B。进入搭配页后等待摇杆回中与攻击键松开，再接受新输入。回到战斗后，装备所用的按键要松开再按才能出招。正在飞行的弹道和冷却从暂停的时刻接着走。
- 搭配、库存、武器等级、能量和当前这一轮攻击随同一局保存。旧进度按原主武器优先填 X，再从已装备的不同武器与大招里补 Y、B，其余进入武器库，地图和成长沿用当前冒险。已开始的首领战保留已打掉的血量和阶段。

## 首领试玩目标

先测单轮攻击规则带来的实际交战节奏。首领开战时按可用单招的输出估算血量，避免把武器库所有伤害加起来。战斗中换装时沿用开战血量。保留蓄力提示和破绽，观察孩子能否看清几轮招式、能否在破绽里用擅长的攻击反击。重点试开局单武器、后期高等级武器、交替连按三键以及首领战中途换装，再根据交战时长微调。

## 验证

- 浏览器用隔离存档进入首领房，选泡泡、绑到 K、返回暂停、继续并打出泡泡。刷新续关仍保留绑定。
- 隔离桌面版模拟 Xbox 验证 Menu 暂停、方向键进入圆环、左摇杆指向、Y 装备、B 交换、Menu 返回及库存超过八件时用 RB 翻页。
- 引擎回归覆盖三把武器同按、每把各自冷却、武器与大招互斥、途中换装、旧档迁移、恢复在途弹道、跨关保留和首领开战血量。高强化弯刀模拟打完各世界首领用了 13.06～13.68 秒，各出招三轮。
