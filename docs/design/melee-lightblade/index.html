打开游戏试用
沿用同一个攻击键近战与远程可同时攻击光刀基础伤害 72基础间隔 0.4 秒

尚未播放。点击任意音效开始试听。

每次只播放一段声音，点击其他按钮会立即停止上一段。页面不会自动播放，也不会读取或修改游戏存档。

光刀声音来源：命中与击破直接使用已验证的《忍者龙剑传 III》原版敌人击破样本（Tecmo，1991，声音命令 0x2D）。出招声是同底样前 95 毫秒加淡出的衍生短音，不是原游戏挥刀声。

八种远程武器：命中与击破是独立制作的红白机风格短音，以不同音高、节奏和噪声尾音区分；不是从原游戏提取的录音。发射声保留现有设计。

此页可离线试听本地资源；“打开游戏试用”需要本机游戏服务正在运行。
