# 近战光刀与独立命中音效

2026-11-17，按用户提供的《忍者龙剑传》截图直接接入游戏。本次增加 `lightblade`，八种远程武器继续保留。四件传统兵器的独立预览仍遵循原来的确认范围。

## 如何使用

营地“自己选择”可选近战光刀，也可在探索奖励中取得；初始仍选一种武器，取得更多武器后按同一个攻击键同时使用。键盘 J、Xbox X、触屏攻击共用规则。四位角色推荐搭配保持原样。

2026-11-20 将基础伤害从 72 提到 96，身前触及距离从 4.2 扩到 5.6 单位，刀光高度从 1.4 增至 2.1 单位。挥斩间隔 0.4 秒，刀光持续 0.18 秒。刀光跟随角色移动和跳跃，每刀方向在出手时确定。同一目标每刀只结算一次，护壳也消耗该次命中。一次挥斩可同时扫到多个相交的敌人，砍碎敌方攻击时按[对冲规则](projectile-clash.md)结算。

叠加武器与双发变成相隔 0.08 秒的多道短斩。攻速同时缩短间隔和挥斩时长，范围本领增加横向与纵向范围，传奇再加 0.6 单位横向范围。已有分裂、冰霜、连锁等效果保留；分裂星弹依然按远程弹道规则移动、命中消失。整轮短斩及派生效果结束后才开始下一轮；其他远程武器独立判断自己的轮次。最高 99 级加双发的一轮约 16 秒，数值手感仍需试玩校准。

保持第 11 版地图和已有存档。保存刀光年龄、已命中目标、待发短斩和剩余冷却；暂停不推进，读档不重复伤害。没有重置家庭存档、画册或成长。

## 声音与素材

2026-11-20 起，游戏优先播放用户提供的 NES《忍者龙剑传》初代音效包。原样保留选中的 11 个 WAV，运行时按事件调整音量和远程武器的播放速度。配置见 [音效映射](../../../public/audio/combat/fc-ninja-gaiden/manifest.json)。

- 光刀出招使用 `01.wav`（挥刀），命中使用 `10.wav`（撞击），击破使用 `13.wav`，砍碎敌方攻击使用 `23.wav`（兵器碰撞）。光刀四种声音按原速播放。
- 八种远程武器分别配置出弹和命中音。圆月弯刀、回旋星镖用回旋镖出手，彩笔火龙用火轮出手。击破共用 `13.wav`，各武器按自己的速度播放。
- 音效包的编号与具名音轨通过比较时序和能量包络核对。源包自带的 `Readme.txt` 标注提取者 Nai255。素材均直接来自用户提供的 ZIP。[具名音轨表](https://nesninja.com/game/nes/ninja-gaiden/music)

### 原有音效和试听页

专用音效包缺失时使用原有音效。下列说明和原试听页记录的是此前的素材组合。

- 光刀命中与击破：直接使用项目先前验证的《忍者龙剑传 III》敌人击破声，声音命令 `0x2D`；与底样字节一致。
- 光刀出招：同底样前 95 ms 加淡出的短音，**不是原游戏挥刀命令 `0x06` 的录音**。当前未取得能可靠确认的原版挥刀样本。
- 八种远程武器的命中与击破：独立制作的 NES 风格音色，分别使用不同的音高、节奏、脉冲占空比和噪声尾音。每类保留三个变体。不是从原游戏提取的八条录音。
- 派生爆炸、花田和分裂星弹保留原发射武器的音色；实际碰到护盾或首领伤害上限时仍有武器命中声音。普通击败不再叠通用拾取花朵声；首领胜利提示保留。
- 新白色短刀光 PNG 由 ImageGen 参考用户截图和现有彩笔素材生成。营地近战预览按实际角色与攻击的相对比例放大，避免刀光落在脚边；正式关卡不附带无关泡泡光罩。

声音来源与处理参数见 `public/audio/combat/source/source.json`、`public/audio/combat/design.json`；可用 `scripts/build-combat-audio.py` 重建。本目录 `index.html` 可离线试听九种武器的出招、命中和击破，共 27 段。
