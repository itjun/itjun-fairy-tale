# 玩家攻击与敌方技能对冲

2026-11-20 更新。小怪和 BOSS 发出的攻击实体只有近战挥斩能砍碎，包括飞行弹、喷射、地面冲击波、墨迹与藤蔓。远程弹道穿过敌弹，延迟脉冲和光刀分裂出的星弹也没有抵消能力。

一次抵消消耗当前刀光与一发敌方攻击，其余待发刀光继续。判定扫过敌弹上一帧到当前帧的路径，在检查敌弹是否伤到玩家之前结算。抵消播放彩笔闪光和兵器碰撞声，专用音效缺失时播放格挡声。抵消不触发连锁、分裂、击败奖励或充能。

敌人身体碰撞、冲撞本体和地图陷阱仍需移动或跳跃躲避。彩虹净化、星云甘霖等独立防御效果沿用原规则。第 11 版存档继续可读，被砍碎的敌弹和已消耗的刀光不会写入存档，恢复中的刀光保留出手时的尺寸和伤害。

回归覆盖左右挥斩、高速敌弹、一刀一发、错层、延迟连斩与保存恢复。八种远程武器、延迟脉冲与分裂星弹均检查敌弹仍然有效，实战引擎另验证敌弹可以穿过远程武器后打伤玩家。
