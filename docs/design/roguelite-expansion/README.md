# 跳台肉鸽扩展提案

2026-11-12。用户已确认组合冒险稿和休息点稿可作为开发依据。本轮已实现战后选择、分岔探险和休息点搭配；技能贯穿本次冒险，下一关继续保留，仍只用移动、跳跃和攻击。

## 当前实现

- 新冒险采用生成版本 2；原有版本 1 地图、积分与临时技能存档继续按旧规则恢复。
- 八关沿用各自独立的区域库和机关主线，随机加入能汇合的上下分岔、怪物组合与奖励方向。新增分岔不依赖特殊技能。
- 12 种怪兽、6 种武器、18 项强化；共同收集，每位玩家各装备一种武器和最多三个强化。
- 新模块分别负责目录、地图、成长、武器与怪物行为；真实游戏和休息点试用共用武器模拟。
- 完成状态、待选卡、已领奖励、怪物状态、装备和技能等级随本机续关保存。家庭记录未用作测试数据。

### 组合方向的界面衔接

[组合效果稿](combined-adventure.png)：战后选择为当前主界面，场景内呈现下一处分岔和休息点入口。沿用三张已选方向图及原始女孩素材生成；已获用户确认；这是设计依据，实机验证另见根目录 `design-qa.md`。

- 正常探索只显示游戏场景、简洁状态和分岔路牌。路牌说明将遇到的怪物及奖励倾向，不保证具体某张技能卡。
- 完成挑战时，在安全区域暂停世界，显示三张候选卡。选择即领取并保存，之后恢复探索；不把武器配置菜单叠在候选卡上。
- 休息点在场景里是可辨认的彩笔小工作台。点击后打开搭配界面，可选已有武器、装配强化并试用；“带上出发”返回原场景。此入口不增加战斗快捷键。
- 图中的下一处分岔与工作台是环境提示，奖励选择期间不可同时操作；三种功能按时机出现，避免界面一次挤满。
- 本次冒险获得的能力跨关保留，界面不再显示旧式 32 秒倒计时。新局才重新构筑，暂停和恢复不重抽候选。

## 一次冒险的节奏

进入主题关卡 → 观察两条路线及奖励方向 → 跳跃、机关或战斗 → 获得三选一 → 新技能改变下一段打法 → 安全点 → 下一段 / 下一关。

- 保留原八关名称与不同结构；每次新冒险随机区域拓扑、分岔、怪物组合、武器机会和技能候选，不只移动几块平台。
- 开始只使用现有移动、跳跃和攻击键。复杂度来自组合，不增加一排主动技能快捷键。
- 普通怪必给积分，可掉落技能碎片；累计完成一个明确的小目标后，在安全点触发选择。精英或路线挑战提供确定的奖励机会，不以运气决定能否成长。
- 新冒险出发前选择一次；每关首段、中段、末段各给一次路线选择，首次击败精英和累计击败六只怪各给一次选择。排队到角色安全落地后暂停领取，避免每只怪都弹窗。实际密度仍需儿童试玩校准。
- 优先提供适配当前武器的强化和未收集的武器，再补足三个不同候选；全部武器收齐后补充有效强化。剩余未满级选项不足三项时只显示有效项，全满时跳过。
- 怪物与挑战影响候选池而非唯一掉落：飞行怪偏追踪/散射，成群怪偏分裂/范围，雪地挑战偏减速，跳台挑战偏空中控制。至少一项适用于当前装备。
- 选技能时暂停整个世界；在安全位置恢复。选项大图标加一句效果，不要求孩子理解概率、暴击率或复杂数值。

## 十二种怪兽

保留三种已有身份并加强行为，再新增九种。每种至少有可辨认的动作、预告和应对方式；不靠换色或堆血量充数。

| 怪兽 | 行为差异 | 倾向奖励 |
| --- | --- | --- |
| 果冻怪 | 慢巡逻，压扁后跳一下，入门目标 | 连发、范围 |
| 叶子怪 | 先蹲下，再短距离跳跃 | 回旋、空中转向 |
| 云朵怪 | 沿可读的上下轨迹浮动 | 散射、追踪 |
| 弹跳蘑菇 | 蓄力变扁，再向上弹跳 | 分裂、弹跳 |
| 贝壳蟹 | 横向快走后停下休息 | 双发、加宽 |
| 泡泡鱼 | 喷出缓慢、可击破的泡泡 | 泡泡范围、滞留 |
| 雪球团 | 先摇晃提示，再滚过一小段平台 | 冰霜、护罩 |
| 喷雪花 | 固定站位，抬头后喷扇形雪花 | 散射、远投 |
| 松果松鼠 | 抛物线投掷，投前举起松果 | 花种、连锁 |
| 萤火虫 | 短暂停留，再沿亮线移动 | 追踪、萤火伙伴 |
| 发条玩具 | 摇晃预告后短冲刺，随后休息 | 回旋、护罩 |
| 糖果团 | 击败后变成两只小糖球，最多分裂一次 | 分裂、磁吸 |

各主题从适合的池子中抽取，按主题组合。精英复用清晰的基本行为，加一个可读变化；可以有蘑菇守卫等放大变体，但不计作额外一种基础怪。早期局部同时活跃一至两只，后期两至三只；“更多怪兽”首先体现种类与遭遇变化，不挤满安全落台。

所有攻击有明显动作预告，颜色不是唯一提示。保留无限生命、温柔恢复、短暂无敌；不加入血腥表现和失败惩罚。光刃仍穿平台、穿沿路小怪至前方屏幕边缘，每发对同怪只命中一次；不能为了新怪擅自取消既有能力。

## 六种武器

| 武器 | 核心打法 |
| --- | --- |
| 贯穿光刃 | 直线贯穿整段前方屏幕，保留现有规则 |
| 魔法泡泡 | 较慢飞行，接触后范围爆开 |
| 彩虹星雨 | 扇形散射，覆盖高低不同目标 |
| 回旋星镖 | 去程、返程形成轨迹，每段对每怪各命中至多一次 |
| 花种弹 | 抛物线越过高低差，落地开花产生短范围效果 |
| 萤火法杖 | 发出轻微追踪的萤光，帮助瞄准空中目标 |

一次装备一种主武器；候选卡明确标注“新武器，选好就装备”，点击后装备，原武器仍可在休息点取回。所有武器使用同一攻击键，无弹药和换弹。基本光刃可完成全部主线，新武器创造打法差异而非通关门票。

## 十八个强化

六个通用变化：双发、分裂、冰霜减速、连锁光点、范围加宽、轻快连发。

六个专属变化：光刃变宽、泡泡滞留、星雨增扇、星镖回程分裂、花种二次开花、萤火追加追踪。

六个辅助变化：宝物磁吸、轻碰护罩、空中转向增强、落地小光环、同行萤火、击败后短暂加速。

示例：泡泡 + 滞留 + 范围加宽形成控场；星镖 + 回程分裂 + 冰霜形成往返减速；星雨 + 增扇 + 追踪型武器替换机会形成对空路线。不能把“追踪型武器”当成已装备星雨的隐式强化，候选需明确是替换武器还是添加效果。

- 最多同时激活三个强化；数值类最高三级，二元效果为一级。满位时新本领收入收藏，在休息点点掉一个已装备本领再装上；切换武器会取下不兼容的专属强化，但不丢失它。
- 图标、轨迹和命中效果都要区分，兼顾减少动态效果偏好。
- 休息点搭配已选中；只在安全点调整已获得强化，点击即可，不强制拖拽。

## 成长、双人与存档

- 已确认把新系统从 32 秒临时替换改为本次冒险持续成长，并在“去下一关”时保留。
- 回花园或退出保存当前冒险；只有明确“新冒险”才清空本次搭配，不删除历史成绩、成就或家庭存档。
- 双人共享已获得武器与强化库，各自装备；世界暂停后依次选择，界面明确当前玩家，奖励与积分只结算一次。
- 随存档保存生成版本、规则版本、冒险种子、每关子种子、地图、怪物及奖励状态、武器、强化、待选候选和已选结果。刷新、掉落和恢复都不重抽候选。
- 新地图采用新生成版本；旧存档继续旧规则或明确转换，不能用新生成器重建一半的旧局。旧成绩保持原值，打怪/宝物/通关分沿既有规则版本核验。
- 暂停、失焦、选择技能和退出清空攻击输入；正在选择时保存恢复仍停在原候选，不重复发奖励。

## 地图约束与验收

- 八关各自使用独立区域库和连接规则，必经内容规模逐关增加。分岔能汇合，主线不依赖随机抽到的技能；可选能力捷径必须有基础操作替代路线。
- 先保证基础跳跃可达和安全恢复点，再放机关、怪物与奖励。前后关以必要路段、操作组合和遭遇规模增加内容，不靠等待或堆血拖时间。
- 检查多种子可达性、无技能主线通关、所有怪物预告和应对、所有武器命中边界、组合上限、选择时暂停、双人并发领取、恢复不重抽不刷分、旧存档与旧成绩兼容。
- 实机验证需用独立测试存档；已运行本地预览和验证，不使用家庭记录作为演示数据。

实现与验收记录见根目录 `design-qa.md`；本轮只在本机开发、构建和安装，不提交、推送或发布。
