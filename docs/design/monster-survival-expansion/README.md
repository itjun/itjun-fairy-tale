# 怪物、生存与资源扩展提案

日期：2026-11-12。状态：用户已确认前两张合并开发，并授权本机构建安装启动；第三张仅保留。本文中的新名称是候选怪物、技能或玩法描述，不替换已有功能名。

## 用户已明确的需求

- 怪物种类和数量都需要增加。
- 技能不能只偏攻击，要增加生存、资源恢复和回收。
- 融入女儿的新画，沿用她的真实人物和笔触。
- 探索跳台之外还能创作的游戏类型。

“回资源类”暂按体力恢复、材料获取、重复奖励回收理解。现有武器没有弹药或法力消耗，本提案不为增加回蓝技能引入额外资源条。

## 当前实现观察

检查来源：`shared/adventure-catalog.js`、`shared/campaign.js`、`shared/adventure-world.js`、`src/game/adventure.js`、`src/game/engine.js`。以下是源码检查，未据此声称完成运行复现。

- 全局有 12 种怪物，每个主题的候选池只有 4 种。基础生成每区域目标为 3～6 只，再由冒险扩展增加上路怪物和分裂子怪；实际数量受可用平台影响。
- 6 种武器、18 项强化；已有磁吸、受伤保护、空中转向等辅助，缺少明确的条件回血和资源回收体系。
- 碎片奖励只在 `fragments === 6` 时排入队列，之后没有连续里程碑。
- 各区域精英共用奖励标识 `elite`，领奖去重会使后续精英奖励被视为已领取。应按关卡与精英实体建立独立身份，并兼容旧存档。
- 可装备强化只有 3 项，扩展时需验证攻击、生存、资源混搭是否值得选，避免强迫孩子全部装备攻击。人物天赋仍独立保留。

## 跳台扩展建议

### 怪物：12 种扩展至 24 种

这是已选定的内容目标。保留已有 12 种，新增 12 种有实际行为差异的怪物；每个主题候选池由 4 种扩为 6～8 种。按主题选取、按行为搭配，不把每一种塞进每关。

| 候选怪物 | 行为差异 | 孩子可以怎么应对 |
| --- | --- | --- |
| 花盆怪 | 慢走，停下后沿地面伸出短藤 | 看到预告后跳过或远程攻击 |
| 小伞怪 | 张伞缓降，收伞时落地停顿 | 在落地空隙攻击 |
| 铃铛哨兵 | 先晃铃，随后唤醒附近休眠怪 | 优先打掉哨兵，控制遭遇规模 |
| 墨滴怪 | 交替长短跳，落地留短暂减速墨点 | 选择干净落点，墨点不额外扣血 |
| 叶盾怪 | 蓄力时正面减伤，冲刺后露出空隙 | 绕后或等停顿；光刃仍贯穿 |
| 毛线虫 | 长身体沿路线爬行，碰墙掉头 | 从头尾空隙通过，身体不重复计伤 |
| 灯笼蛾 | 围绕固定灯点盘旋，亮起后短冲刺 | 观察亮灯预告，再通过路径 |
| 枕头守卫 | 敲地发出一圈可跳过的低矮波纹 | 跳过波纹，在歇息时攻击 |
| 沙堡怪 | 固定地点筑起可打碎小沙堆 | 清理障碍，必经路线始终可通 |
| 冰锥团 | 天花板标记落点后下落，落地变慢走 | 离开标记，再对付地面形态 |
| 地洞团 | 在预先可见的洞口间转移 | 等它露头，洞口不设在复活点 |
| 彩笔桶 | 限量放出两只小墨滴，随后停止 | 优先打桶；子怪不无限刷奖励 |

数量先按相同关卡、相同种子下可遇到的独立敌人增加约 50%～80% 作为调参目标，不靠提高血量拖时间。早期同屏主动攻击不超过 3 只，后期先限制为 4～5 只；同一时刻优先只让一个高威胁招式启动。屏外不发射攻击，检查点、休息点和必要落脚区留安全空间。分裂、召唤纳入总预算。

遭遇节奏以“小组战斗 → 收集或机关 → 安全缓冲”为单位。随机化怪物组合与站位，保留可达路线、预告与逃离空间。新局采用新生成版本；同局死亡、暂停、加载不重抽敌人、掉落或奖励。

### 强化：18 项扩展至 36 项

新增 18 项的候选分配为生存 6、资源 6、控制与探索 6。以下效果和数字均为待试玩参数。

| 类别 | 候选技能 | 具体作用与限制 |
| --- | --- | --- |
| 生存 | 花瓣护心 | 击败独立怪物收集花瓣，每 6 片回 1 格体力；满血不消耗花瓣 |
| 生存 | 叶片护甲 | 每个独立遭遇挡一次怪物伤害；不挡掉坑，不靠重进区域刷新 |
| 生存 | 软软棉衣 | 减少受伤击退距离，降低连锁掉坑风险；仍扣正常体力 |
| 生存 | 安稳落脚 | 大落差落地后短暂防接触伤害；只在有地面时生效，不拦截坑底死亡 |
| 生存 | 小小勇气 | 剩 1 格体力时触发一次短保护，每关限一次 |
| 生存 | 守护花环 | 完成独立遭遇后获得一次护罩；与爸爸天赋有明确消耗顺序，不叠成永久免伤 |
| 资源 | 彩笔回收 | 将本次未选的奖励机会换成碎片；每次只能选奖励或回收，不能两头领取 |
| 资源 | 重复变宝 | 已满级或重复拥有的奖励可换碎片，避免无用选项 |
| 资源 | 补给口袋 | 独立精英必掉一份补给材料，补给只结算一次 |
| 资源 | 节约巧手 | 营地兑换恢复物少花材料，有价格下限，不能循环套利 |
| 资源 | 备用点心 | 将拾取的满血恢复物存一份，受伤后自动消耗；容量有限 |
| 资源 | 探路奖励 | 首次完成支路挑战获得材料，回走和读档不重复发放 |
| 控制与探索 | 泡泡束缚 | 间隔触发一次短束缚，精英持续时间更短 |
| 控制与探索 | 花香诱饵 | 攻击时偶尔留下短暂诱饵，转移附近怪物注意 |
| 控制与探索 | 清风推开 | 受伤后推开近身怪，有冷却，不能推开地形机关 |
| 控制与探索 | 彩虹净化 | 间隔清除附近少量敌方弹丸，有数量上限 |
| 控制与探索 | 宝物指路 | 提示附近未取奖励的大致方向，不自动完成支线 |
| 控制与探索 | 轻羽缓落 | 空中按住跳跃可短暂缓降；不增加妹妹之外的第二次跳跃 |

这轮优先把技能变成可混搭的选择，不增加操作键。继续使用现有三强化槽做首轮验证，人物天赋不占槽；若三槽使生存和资源始终不值得装备，再单独评估槽位方案。

### 奖励与资源规则

- 普通成长三选一至少包含一个非攻击选项；有足够候选时展示攻击、生存、资源各一项。低血时保证可用的生存或恢复选项，而不是只提高随机概率。
- 第一份击败奖励仍可在 6 只出现，之后按固定击败里程碑继续奖励；具体间隔随关卡长度调节。临近的精英与里程碑事件可排队在同一安全停顿处理，避免频繁打断。
- 精英事件按关卡、种子和独立敌人 ID 去重。生成后的奖励候选保存下来，重开弹窗不重抽。
- 保留“总击败进度”用于里程碑，另存“可花费碎片余额”；不能直接把现有累计计数当货币扣掉。
- 在现有休息点增加明确消耗的恢复兑换，例如碎片换 1 格体力。单点兑换次数有限，不因进出、暂停、刷新而重置。
- 历史积分仍是成绩，不作为货币花费；碎片、花瓣、备用补给、已领取事件随同局存档并跨关保留。
- 新冒险仍为 3 格体力、9 条命，旧有限生命存档保留剩余命数。恢复技能回体力，默认不补命。死亡扣命和复活流程不变，不能无限复活。
- 一次奖励选择、回收或兑换必须同时落账与标记已消费。死亡、存档、重复点击都不能造成重复获得。

## 跳台之外的游戏候选

以下名称只描述玩法方向，尚未授权新项目实现。

| 方向 | 一轮怎么玩 | 新画怎么用 | 与现有小游戏的区别 |
| --- | --- | --- | --- |
| 俯视探索解谜（优先） | 接任务 → 探索区域 → 找材料或解机关 → 打开新地点 | 高塔作为可进入地标，原人物作为伙伴，花园与紫色地面构成不同区域 | 自由走动、地图连通与连续故事，而非固定场景找物 |
| 自由搭建小镇 | 摆房子和道路 → 接通目的地 → 邀请伙伴入住 | 高塔、花、人物可做真实原画贴纸组件 | 以自由创造为主，没有唯一正确布局 |
| 画路线送伙伴回家 | 观察道路 → 拖拽连路线 → 试走 → 修改路线 | 人物各有目标小屋，太阳和花作路标 | 空间规划和可撤销试错，不考验跳跃反应 |
| 轻量守护花园 | 放花盆守卫 → 观察短波次 → 换位置或选强化 | 花朵成为守卫，新增怪物作为顽皮来客 | 位置策略和组合；复杂度高于前三项，适合后续再做 |
| 互动故事剧场 | 摆人物和道具 → 选择行动 → 演出一小段故事 | 整幅画变成舞台，人物保持原始造型 | 女儿可以自己编故事，弱化输赢与数值 |

建议先完善跳台的怪物和生存资源，再选一个新玩法做小范围试用。探索解谜先做“修桥 → 进入高塔 → 找回花园钥匙”的完整短篇，确认孩子愿意探索后再扩地图。

## 选定后的验收范围

1. 新增怪物的轮廓、预告和实际行为可区分；地图抽样验证安全落点、可达性与遭遇预算。
2. 不同精英都能领奖，普通击败里程碑持续触发；同一事件重复加载或点击不重复发放。
3. 生存与资源技能实际生效，满血、残血、死亡、跨关、暂停、刷新和存档恢复均一致；人物天赋没有被覆盖。
4. 兑换扣费、回收和领取同步保存；旧存档仍可读取，积分与材料分离。
5. 本机使用隔离存档构建运行，打开浏览器实际试玩；桌面与儿童试玩结果分别记录。生成稿不作为测试证据。

实现与本机验证结果见完成后的验证记录；不提交、推送或发布，家庭存档不用于自动验收。
