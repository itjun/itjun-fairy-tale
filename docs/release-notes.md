# 花园王国 v0.5.1

- 四位角色各有默认武器与本领，支持自行更换并记住搭配；五类主武器和四种充能大招可叠加成长。
- 奖励分普通、稀有、史诗、传奇，每个小关至少提供一个有效传奇选项。
- 新增武器打击音效及六种彩笔怪物，增加遭遇和中段首领，共 56 场首领战。
- 新冒险默认 3 条命，每条初始 100 血；受击扣血，每次血条耗尽暂停选择继续或重来。旧存档迁移并保留成长。
- 所有系统默认无边框、非全屏窗口，移除系统与自绘顶部窗体条，保留彩笔画风。

提供 macOS Apple Silicon / Intel 的 DMG、ZIP，以及 Windows ARM64 / x64 安装程序。macOS 安装包采用临时签名，未公证；Windows 安装包未签名。

本机通过 157 项自动化测试与桌面保存、重开验证。Windows 实机与儿童试玩难度尚待验证。
