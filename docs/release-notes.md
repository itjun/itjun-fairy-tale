## 花园王国 0.3.1

- 八关改为类肉鸽的随机冒险：每关固定主题与特色玩法，每次新局随机生成地图拓扑、区域组合、宝物种类与位置、小怪组合和巡逻布局；流程规模逐关增加，随机结果保证可达，同一局掉落、暂停和恢复不重抽地图。
- 新增冰面滑行、传送带、开关吊桥、横纵向升降台等机关，以及树屋、风车、灯塔、城堡剖面、街景等彩笔场景元素；镜头随角色上下跟随。
- 主角可以远程攻击（J / Enter / 触屏攻击键）：光刃贯穿当前屏幕，穿过平台并连续命中沿途小怪；击败小怪也有奖励分。
- 探索途中有魔法泡泡与彩虹星雨技能奖励：泡泡爆开造成范围伤害，星雨五向散开；强化持续 32 秒，双人共享，获得与施放都有彩笔特效。
- 计分规则 v3：宝物积分 + 打怪积分 + 通关奖励，历史积分保留；通关后一键直达下一关，沿用当前单人 / 双人模式。
- 暂停与退出可续关：本局进度、技能强化与已领奖励随同保存，休息时不计时；花园首页提供“继续探险 / 新冒险”入口，游戏弹窗简化。
- macOS 构建安装后自动清理旧构建副本并归档正式安装包。

## 花园王国 0.2.0

- 八个彩笔世界加入三种上下路线：阶梯分层、树屋升降回环、地面与地下切换；每次进入会随机调整台面与小怪位置。
- 新增粉果冻、绿叶子和飞行绒球小怪。踩头可以反弹，侧碰会轻轻弹开并提供短暂保护，不扣积分。
- 新增升降叶台、弹簧花和高台下跳，镜头随角色左右与上下移动；双人分开太远会在静止安全台会合。
- 保留女儿彩笔画风、无限生命、九种宝物积分和原有成绩。增加路线提示，改善窄窗口起点视野和触屏下跳操作。
- 新增多层落地、小怪碰撞、升降载人、地下恢复与八关随机地图可达性测试。

## 桌面版功能

- 女儿原画风格的八个彩笔世界，随机横版跳台、无限生命、单人及亲子双人模式。
- 九种宝物不同分值，拾取加分动画，本机 SQLite 成绩本与时间曲线。
- macOS / Windows 启动全屏，内置全部素材与中文手写字体，离线游玩。
- 自动检查 GitHub 正式新版，后台下载，休息时保存成绩后自动安装重启。
- `python build.py` 一键关闭本游戏旧进程、构建、安装、启动。

### 下载

- Mac Apple Silicon（M 系列）：`mac-arm64.dmg`
- Mac Intel：`mac-x64.dmg`
- Windows 常见 Intel / AMD 电脑：`win-x64.exe`
- Windows ARM 电脑：`win-arm64.exe`

ZIP 也是 Mac 自动更新包；`garden-update.json` 是更新清单，`SHA256SUMS.txt` 可校验下载文件。

目前 Mac 为 ad-hoc 签名，未做 Apple Developer ID 公证；Windows 未做发布者签名。首次打开可能出现系统来源确认，请仅从本仓库下载。Mac 请先移到“应用程序”目录运行。更新保留个人成绩；更新后需要重新选关，未结束的挑战会先保存。

本机已验证 Mac ARM64；其他架构提供构建产物，尚无对应真机游戏验收。
