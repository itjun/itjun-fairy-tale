# 花园王国 v0.5.2

- 接入 Xbox 手柄，支持跳台战斗、角色装备、菜单、奖励与死亡弹窗、三个小游戏和花园贴纸。
- 增加摇杆死区、震动开关和按键提示；断连或切换窗口自动暂停，重连后手动继续，避免误选奖励。
- 首页改为游戏主菜单，采用 11 幅原画元素重排的彩笔轮播背景；选项、画展与成就使用整页布局。
- 桌面托盘提供全屏、重新启动和退出；重启前保存进度，保存失败可重试。

操作：左摇杆／方向键移动，A 跳跃，X／RT 攻击，Y 大招，Menu 暂停，B 返回。完整说明位于“选项 → 游戏设置”。

提供 macOS Apple Silicon / Intel 的 DMG、ZIP，以及 Windows ARM64 / x64 安装程序。macOS 安装包采用临时签名，未公证；Windows 安装包未签名。

本机通过 163 项自动化测试、桌面保存重开、托盘重启与模拟手柄全流程验证。实体 Xbox 手柄、Windows 实机及 USB／蓝牙震动尚待验证。
