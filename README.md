# 花园王国

根据一位 6 岁小画家的 11 幅作品制作的亲子游戏。Three.js 渲染立体跳台和彩笔纸片角色；城堡、家人、花朵、彩虹与冰淇淋来自原画风格的生成素材。保留原花园互动与全部原画画展。按钮与弹窗使用真实彩笔纸张纹理，中文使用随包提供的霞鹜文楷手写字体，离线可用，字体许可见 `public/fonts/OFL.txt`。

## Windows 家庭电脑

1. 安装 Node.js **22.13 或更高版本，建议 24+**。使用新版 Edge / Chrome，开启图形加速，需支持 WebGL 2。
2. 解压整个项目，双击 `启动花园王国.cmd`。第一次自动安装组件，需要联网；之后素材和成绩都在本机。
3. 构建完成、服务启动后会打开浏览器。保持命令窗口打开，结束时按 Ctrl+C。若浏览器没有自动打开，访问 http://127.0.0.1:4173/ 。

也可以手动启动：

```sh
npm ci
npm run build
npm run play
```

无需复制其他电脑的 `node_modules`。服务默认只监听本机 `127.0.0.1:4173`，没有公开部署、账号、广告、付费或远程数据收集。

**积分需要 Node 服务。** 不能直接双击 HTML，也不能只把 `dist/client/` 放到静态服务器。保留的 Sites worker 仅供原有静态运行环境使用，不提供本轮 SQLite 接口。

## 关卡与操作

首页点“去跳台探险”，选关和单人 / 双人模式。八个关卡均可直接进入，每次挑战都会重新随机排列跳台，所有相邻台都按跳跃能力限制间距和高度。

| 关卡 | 场景元素 | 跳台数 | 通关目标 | 通关奖励 |
| --- | --- | --- | --- | --- |
| 彩虹花园 | 第 1、2、6、9 幅：彩虹、城堡、心形花 | 8 | 至少 4 件宝物，到达最后跳台 | 50 分 |
| 家人小镇 | 第 3、4、7、11 幅：家人、小屋、双塔 | 10 | 至少 6 件宝物，到达最后跳台 | 80 分 |
| 甜甜城堡 | 第 5、8、10 幅：蓝粉城堡、冰淇淋、爱心 | 12 | 至少 8 件宝物，到达最后跳台 | 100 分 |
| 贝壳海边 | 灯塔、帆船、海浪、沙堡 | 10 | 至少 6 件宝物，到达最后跳台 | 80 分 |
| 风车草地 | 风车、蝴蝶、小兔、奶牛 | 9 | 至少 5 件宝物，到达最后跳台 | 70 分 |
| 雪人乐园 | 雪山、雪人、企鹅、冰屋 | 11 | 至少 7 件宝物，到达最后跳台 | 90 分 |
| 蘑菇森林 | 大树、树屋、松鼠、猫头鹰 | 12 | 至少 7 件宝物，到达最后跳台 | 90 分 |
| 卡通梦工场 | 原创机器人、恐龙、火箭、气球和糖果屋 | 12 | 至少 8 件宝物，到达最后跳台 | 100 分 |

前三关组合原画中的元素；后五关沿用彩笔画风，扩展自然风景与原创卡通角色。海边用沙黄色跳台，雪地用浅蓝白雪跳台，卡通世界用粉紫色跳台。

| 玩家 | 移动 | 跳跃 |
| --- | --- | --- |
| 小女孩（单人） | A / D 或 ← / → | 空格、W 或 ↑ |
| 小女孩（双人） | A / D | 空格或 W |
| 爸爸（双人） | ← / → | ↑ |

屏幕箭头与“跳”也可操作小女孩；双人需要实体键盘。不自动奔跑，接近边缘时按方向和跳跃，空中也能调整。

- **每件宝物 10 分**，通关再加奖励；双人共享积分，同一件宝物不会重复计分。
- **无限生命、不限时、掉落不扣分。** 云朵会把角色送回刚才站稳的平台，已收集宝物保留。可主动点“回安全台”。
- 保留整关平台，可以回头找漏掉的宝物；双人距离太远会在安全台会合。
- P / Esc 暂停，切换窗口也会暂停；休息时不计时。
- 暂停后可以“结束并保存”或换随机地图；通关可进入下一关或再挑战。
- 离开或刷新后不恢复跳台位置，重新出发算新一次游玩；已有积分记录保留。

可收集小花、爱心、星星、彩虹、冰淇淋、贝壳、雪花、蘑菇和气球，共九种宝物。每关有不同的组合，随机排列后交替出现；拾取提示会说出宝物名字，结算展示本次收集的种类与数量。旧成绩继续保留，历史花朵数量统一显示为“收集”。

## 成绩本与 SQLite

首页、选关和结算页面都能打开“我的成绩本”。每次点击出发进入一关，创建一条记录；暂停、继续、保存重试不会增加次数。中途结束和 0 分游玩也会记录。

- 汇总包含累计分数、次数、最高分、平均分、通关数与游玩时长。
- 支持今天、近 7 天、近 30 天、全部和自定义日期，也可按关卡筛选。
- 曲线按真实游玩开始时间排列，不同颜色代表不同关卡；可切换每日平均。没玩的日期不补零。
- 每日平均按当前电脑时区、各关卡分别计算；超过 1,000 次记录自动用每日平均，明细每页 20 条。
- 汇总与曲线包含进行中、暂停和已结束的记录。未正常退出的记录超过一分钟未更新显示“中途离开”，已经保存的分数仍保留。

收集宝物和推进跳台时立即保存，并每 3 秒保存一次时长；暂停、通关、结束和离开时再次保存。只有服务确认写库，界面才显示“积分已保存到这台电脑”。服务断开时会暂存到当前浏览器，保留页面可重试，重新打开游戏也会补存。异常断电仍可能丢失尚未写入或尚未暂存的最后几秒；清理浏览器数据会删除尚未补存的队列。

正式数据库是项目下的 **`data/garden.sqlite`**，首次启动自动创建。SQLite 使用 WAL，运行时可能有 `garden.sqlite-wal` 和 `garden.sqlite-shm`。**备份前先关闭游戏服务，然后复制整个 `data/` 目录。** 升级程序时保留此目录；换电脑时也一起迁移。旧版本没有记录积分，过去的游玩无法追溯。安装包不附带测试成绩。

## 原花园玩法

找回彩虹、照顾花朵、给一家人分享冰淇淋，完成后开派对；还可以贴纸、撤回、保存花园照片、浏览 11 幅原画。原花园成就存于当前浏览器，与 SQLite 探险成绩分开保存。语音依赖系统中文声音，没有语音仍可玩。

## 开发与验证

```sh
npm ci
npm run dev -- --port 4173
npm test
npm run build
```

- `src/game/`：Three.js 场景、键盘 / 触屏、碰撞、随机平台与结算。
- `shared/levels.js`：八关规则、通关目标与计分。
- `src/scores/`：本地待保存队列、成绩查询、Chart.js 曲线。
- `server/`：Node HTTP 服务与内置 `node:sqlite`，无需额外数据库安装。
- `data/`：正式成绩；可用环境变量 `GARDEN_DB_PATH` 指定隔离测试库。
- `public/assets/`：参考原画生成的 PNG；`public/artworks/`：原画浏览副本，原始附件未修改。
- `tests/`：平台可达性、SQLite 持久化与统计、接口、保存队列、原 Sites runtime 测试。

原有 `.openai/hosting.json`、`worker/` 和构建脚本保留。`npm run build` 输出 `dist/client` 及 Sites 兼容文件；家庭电脑实际使用 `server/index.mjs` 提供页面和 SQLite API。所有运行资源随包交付，无远程 CDN。

已在本机浏览器验证真实通关、积分写入、关卡切换、统计筛选、断开服务后补存。Windows 真机、长时间运行和手机实体多点触控尚未实测。详细证据见 `design-qa.md`。
